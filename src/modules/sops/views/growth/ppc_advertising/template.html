否定关键词筛选标准

🚫 高曝光低点击

  • • 曝光 > 1000
  • • CTR < 0.2%
  • → 词与产品不匹配

⚠️ 高花费低转化

  • • 花费 > $20
  • • 订单 = 0
  • → 流量质量差

🎯 ACOS过高

  • • ACOS > 目标×2
  • • 观察期 > 7天
  • → 转化效率低

📝 无关词

  • • 明显不相关
  • • 竞品品牌词
  • → 人工识别否定
