场景对齐

按广告、Listing、利润、选品等业务场景选技能，不把万能 skill 套到所有问题上。

读清边界

先看能力边界、输入要求与输出格式，再试用；避免把技能当成黑盒提示词。

一键试用

在 Deep Chat 挂载方法论为系统提示词；业务数据、报表与样本由你补充，模型不猜实时市场。

结果可验收

输出要能进入 SOP、报表动作或审稿清单；拒绝「看起来很专业」的空话结论。

Skill Formula

技能使用公式

先把业务问题对齐技能，再让模型按方法论产出。

COPYABLE STRUCTURE
  1. 1. 选场景：广告、Listing、利润、选品等，一次只挂一个主技能。
  2. 2. 读边界：打开详情，确认能力边界、输入要求与输出格式。
  3. 3. 准备输入：粘贴真实报表、竞品页、评论或 ASIN 事实，并标注时间范围。
  4. 4. 挂载试用：Deep Chat 试用挂载系统提示词，或复制全文到外部 Agent。
  5. 5. 补业务数据：在对话里补充样本、毛利约束、禁用词与人工红线。
  6. 6. 验收归档：对照可执行动作与复核点，再沉淀到 SOP 或下一轮作业。

上线前五问

  • 是否用了真实数据，而不是让模型编市场事实？
  • 技能边界是否覆盖本轮问题，而不是万能套用？
  • 输出是否能被运营直接执行或审稿？
  • 缺数据时模型是否会拒绝下结论？
  • 是否有合规、费用、政策的人工复核点？

不要这样用

不要「随便挂一个技能帮我写爆款 Listing」。应先选 Listing 场景技能，读清输入与输出，再粘贴关键词、竞品与评论证据，按可审稿结构产出。

Seller Playbooks

四条高频实战路径

从场景到技能：方法论负责判断与组织，你负责数据与拍板。

Listing 转化

关键词 + 竞品页 + VOC → 标题/五点/A+ 结构与合规自检。

输入：关键词、竞品、评论痛点
处理：意图分组、卖点排序
输出：可审稿文案和风险项

广告分诊

搜索词报表 + 毛利约束 → 加词、否词、降价、预算与 Listing 承接。

输入：点击、花费、订单、ACOS
处理：样本量与目标分桶
输出：保守/激进动作表

利润与定价

费用、FBA、关税与毛利事实 → 定价区间、底线与调价风险。

输入：成本、费用、售价、退货
处理：利润结构与敏感点
输出：可执行价格带

选品与竞品

词库、趋势与竞品页 → 机会点、风险与「可跟进 / 不建议模仿」。

输入：关键词、竞品、评论
处理：机会聚类与证据检查
输出：行动优先级清单

Business Operating Rules

业务规则如何进入技能

把平台规则、报表事实和卖家实践，内化为技能的输入、边界与验收动作。

Listing 合规 先合规，再转化

标题、五点、描述和图片文案必须围绕同一商品事实展开，禁用促销语、夸大声明与无证据认证。

技能要求

输入产品事实与禁用词；输出文案时同步列出可上线 / 需证据 / 不建议写。

关键词口径 分组后再进页面位置

关键词要先按核心词、属性词、场景词、问题词分组，再决定放在标题、五点、A+ 或后台词。

技能要求

要求先分组、再分配位置；不能用未提供的搜索量/销量/排名做判断。

广告样本量 低样本只观察

PPC 动作必须基于点击、花费、订单、ACOS/ROAS 与样本量；低样本不能直接否词或大幅调价。

技能要求

区分加词、否词、降价、提预算、Listing 承接差；每个动作写依据、风险和复查时间。

VOC 证据 评论是责任分发

评论、QA、退货要先聚类，再拆给产品、Listing、客服与合规，避免情绪化空总结。

技能要求

每条洞察带原始证据、严重度、责任方、行动项和验证方式。

利润口径 费用与毛利是事实

定价与利润技能必须以成本、FBA、关税、退货与广告费为输入，不做空中毛利承诺。

技能要求

输出价格带与敏感点时标明假设；缺费用数据时拒绝给「保证利润」结论。

挂载与复核 技能给方法，人来拍板

Deep Chat 挂载提供方法论；最终动作、预算与合规声明必须经过运营人工确认。

技能要求

试用后检查系统提示词与输出验收点；不要把模型输出直接当平台事实提交。
