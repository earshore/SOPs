# 🚀 AI 分析加速 - 快速启动指南

## 立即体验

### 1. 打开 AI 智能分析页面

导航到：`应用中心 > 主分析 > AI 智能分析`

### 2. 选择产品和分析目标

- 选择要分析的产品 ASIN
- 选择分析目标（建议选择全部 8 个）

### 3. 点击"开始分析"

系统将自动使用并行分析，速度提升 4 倍！

## 调整性能设置

### 打开设置面板

点击"开始分析"按钮旁边的 **"性能设置"** 按钮

### 配置选项

#### 1. 最大并发数（推荐：4）

```
1-2  → 网络不稳定时使用
4    → 推荐配置（默认）
6-8  → 网络良好时使用
```

拖动滑块调整，系统会显示：
- 预计加速比
- 预计耗时

#### 2. 启用智能缓存（推荐：开启）

✅ 开启后：
- 相同产品的分析结果缓存 24 小时
- 二次分析速度提升 10 倍
- 可查看缓存统计（项数、大小）
- 可手动清除缓存

#### 3. 失败处理策略（推荐：继续执行）

- **继续执行**：单个目标失败不影响其他（推荐）
- **立即中止**：任何失败都终止整个分析

### 保存设置

点击"保存设置"按钮，配置将永久保存

## 常见问题

### Q1: 为什么速度没有明显提升？

**A:** 检查以下几点：
1. 并发数是否设置为 1（默认是 4）
2. 网络是否稳定
3. 是否触发了 API 限流（降低并发数）

### Q2: 缓存什么时候会失效？

**A:** 以下情况缓存会失效：
1. 24 小时后自动过期
2. 产品数据发生变化
3. 切换分析语言
4. 手动清除缓存

### Q3: 并发数设置多少最好？

**A:** 推荐配置：

```
网络不稳定  → 2
正常使用    → 4（默认）
网络良好    → 6-8
```

### Q4: 会影响分析质量吗？

**A:** 不会！
- 每个目标独立执行
- 使用相同的 LLM 配置
- 保留原有的重试机制
- 失败隔离，不影响其他目标

## 高级技巧

### 技巧 1：首次分析使用高并发

```
首次分析 → 并发=8（快速完成）
后续分析 → 并发=4 + 缓存（更快）
```

### 技巧 2：定期清理缓存

```
每周清理一次缓存
确保使用最新的分析结果
```

### 技巧 3：网络不好时降低并发

```
如果经常失败 → 降低并发数到 2
网络恢复后 → 提高到 4
```
