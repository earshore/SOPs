欧洲站本地化 (Localization) 策略

🚫 拒绝机翻 (No Machine Translation)

直接翻译会导致关键词失效。必须基于当地用户用语习惯埋词。

  • • 英文：Mobile Phone Case
  • • 德文直译：Mobiltelefon-Fall (错误)
  • • 德文地道：Handyhülle (正确流量词)

🌍 统一运营 (Pan-EU Listing)

  • • ASIN共享：使用相同ASIN在5国上架，共享评论(Review)
  • • 图片文案：主图/A+尽量使用图标或英语通用词，减少翻译工作量
  • • 小语种：雇佣本地人或使用高级AI(ChatGPT-4)进行润色

标题 (Title) 编写公式

[品牌] + [核心词] + [场景/人群] + [卖点] + [规格]

✅ 正确示例

BrandX Wireless Bluetooth Headphones for Running, Active Noise Cancelling, 40H Battery, Black

❌ 错误示例

Best Headphones 2024 NEW!!! Amazing Quality Cheap Price Free Shipping

字符限制： 200字符内，移动端显示前70字符

五点描述 (Bullet Points) 埋词逻辑

1
核心功能 + 适配对象 (流量入口) → 例："Passgenau für iPhone 15" (直击精准人群)
2
材质工艺 + 欧标合规 (转化信任) → 用实词 (OEKO-TEX, 304钢) 替代 "High Quality"
3
使用场景 (COSMO/长尾) → 欧洲本土化场景 (如: 阿尔卑斯徒步)
4
供货范围 (Box Contents) → Rufus AI问答，减少“缺件/误解”类退货 (Lieferumfang)
5
技术参数 + 售后 (Rufus优化) → 电压/重量, Rufus参数类问题。禁写 "Lifetime Warranty"

A10/COSMO/Rufus 算法要点

A10：站外流量 + 停留时间 + 转化率
COSMO：场景意图匹配 (前3个Bullet)
Rufus：问答式理解 (后2个Bullet + 参数)

移动端显示确认 (必做)

  • • 标题前70字符表达核心信息
  • • 主图移动端1:1显示是否聚焦
  • • Bullet前3条是否包含卖点
  • • 70%流量来自移动端！

Search Terms 填充规范

✅ 正确做法

  • • 空格分隔关键词
  • • 不重复Title中的词
  • • 包含拼写变体/同义词
  • • 小写即可
  • • 用满250字节

❌ 禁止事项

  • • 逗号或标点分隔
  • • 竞品品牌名
  • • 主观词(best,amazing)
  • • 重复堆砌
  • • ASIN或价格

A+ 内容排版规范

模块1： 品牌Banner (沉浸式场景图，无文字/极少文字)
模块2： Icon 图标 + 短语 (跨越德法意西语言障碍)
模块3： 细节爆炸图 + 侧边高亮 (SEO文字收录)
模块4 (核心)： 对比图表 (Comparison Chart) - 流量闭环/交叉销售
模块5： QA & 技术参数表 (Tech Specs) - 针对理性德国买家
图片规范：970×600px / 300dpi / 白底 / 文字占比≤20%

品牌故事 (Brand Story) 规范

📐 硬性尺寸要求 (背景图)

🖥️ 电脑端 (Desktop) 1464 x 625 px Logo放极左/极右 (中间会被挡)
📱 移动端 (Mobile) 463 x 625 px 独立设计，禁止直接缩放

🃏 卡片组合策略 (精铺版)

1
品牌起源卡 (About Brand)
虚：讲情怀/设计理念。配图：创始人/氛围图 (315x460px)。
2
四图ASIN卡 (Killer)
实：免费关联流量位！放互补爆款或新款，交叉引流。
⚠️ 美工避坑 Checklist:
  • 背景图中央区域会被挡住，严禁放文字
  • 卡片文字要少，移动端滑动快
  • 移动端背景图必须单独裁剪设计
