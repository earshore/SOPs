红线警告 - 零容忍条款

一经发现违反本SOP规定，直接清退，并追究经济责任。亚马逊的关联检测算法持续升级，任何细微的环境泄露都可能导致整批账号被封禁。

关联封号 = 全店库存冻结 + 资金扣押180天
IP泄露 = 多店同时触发二审风险
设备混用 = 浏览器指纹关联（最难解除）

登录环境规范

紫鸟超级浏览器配置

  • 每个店铺创建独立浏览器环境，命名规则：店铺名_站点_序号
  • 指纹设置：UA/时区/语言/分辨率需与IP所在地区匹配（德国站用德国IP+德语时区）
  • 每月检查一次浏览器指纹唯一性，使用 browserleaks.com 检测
  • 禁止在紫鸟环境内登录任何非亚马逊网站（包括Google、淘宝等）

VPS 远程桌面规范

  • 推荐配置：Windows Server 2019+，2核4G内存起步
  • IP类型：静态住宅IP（Luminati/Oxylabs）或干净独享机房IP
  • 一台VPS只登录一个店铺，严禁多店共用VPS
  • 每次登录前用 whatismyipaddress.com 确认IP正确

IP与网络隔离策略

IP分配与管理

  • 每个店铺绑定固定独立IP，记录在《IP资源管理表》
  • IP更换需提前72小时向主管报备，填写《IP变更申请单》
  • IP纯净度检测：scamalytics.com 评分需>50分
  • 欧洲站点建议使用当地国家IP（德国站用德国IP，法国站用法国IP）

绝对禁止行为

  • 禁止 在公司办公网络（包括WiFi）登录任何亚马逊账号
  • 禁止 使用个人手机/平板/家庭电脑登录公司店铺
  • 禁止 在店铺环境内访问私人邮箱、社交媒体、电商平台
  • 禁止 截图/录屏店铺后台发送到非公司群组
  • 禁止 将OTP验证器转移到个人手机或共享给他人

双因子认证 (2FA) 管理规范

OTP设备管理

  • • 公司统一配置专用OTP手机/设备
  • • 每个店铺的OTP存储在独立设备
  • • OTP设备不得带出公司
  • • 离职交接需移交OTP设备

密码规范

  • • 密码长度≥16位，含大小写+数字+符号
  • • 每个店铺使用不同密码
  • • 密码存储在公司密码管理器
  • • 每季度强制更换一次密码

紧急响应

  • • 发现账号异常立即冻结登录
  • • 第一时间通知主管和IT部门
  • • 24小时内更换所有凭证
  • • 检查同环境其他店铺状态
