# Rufus AI 模式验证指南

## 概述

本指南提供了完整的 AI 模式验证流程，帮助您确认 AI 模式是否正确工作。

## 验证工具

### 1. 浏览器控制台快速测试 (推荐)

**文件**: `test/browser-console-test.js`

**使用步骤**:
1. 打开 QA Lab 页面
2. 按 `F12` 打开开发者工具
3. 切换到 `Console` 标签页
4. 复制 `browser-console-test.js` 的内容到控制台
5. 按回车执行

**可用命令**:
- `quickCheck()` - 快速检查所有组件状态
- `testToggle()` - 测试模式切换功能
- `testAI()` - 测试 AI 回答功能
- `showLogs()` - 显示日志过滤提示

### 2. 全流程验证脚本

**文件**: `test/verify-ai-mode-flow.js`

**使用步骤**:
1. 打开 QA Lab 页面
2. 按 `F12` 打开开发者工具
3. 切换到 `Console` 标签页
4. 复制 `verify-ai-mode-flow.js` 的内容到控制台
5. 按回车执行
6. 脚本会自动执行 5 个验证步骤并生成报告

**验证内容**:
- 步骤 1: 检查模块加载状态
- 步骤 2: 检查 LLM 配置状态
- 步骤 3: 测试模式切换功能
- 步骤 4: 分析日志模式
- 步骤 5: 生成验证报告

### 3. AI 模式配置检查

**文件**: `test/check-ai-mode.js`

这是一个详细的配置指南文档，包含：
- 完整的配置步骤
- AI 模式的可见特征
- 调试方法
- 常见问题解决方案

- ✅ qalabState 已加载

运行 `testAI()` 验证：

- ✅ 观察思考状态提示
- ✅ 检查 LLM 调用日志

## AI 模式可见特征

当 AI 模式正常工作时，您应该看到：

### 1. 模式切换按钮
- 紫色背景渐变
- 显示 "🤖 AI 模式"
- 边框颜色: #a855f7

### 2. 思考状态
- 第一阶段: "正在连接大模型..."
- 第二阶段: "正在分析报告内容..."
- 第三阶段: "正在生成智能回答..."
- 思考时长: 800-1300ms

### 3. 消息显示
- 消息头部有紫色徽章 "🤖 AI 模式"
- 徽章带有发光动画效果
- 图标显示为机器人 (fa-robot)

### 4. 成功提示
- Toast 提示: "AI 回答生成成功"
- 副标题: "基于大模型智能分析"

## 常见问题排查

### 问题 1: 模式切换按钮不可见

**检查**:
```javascript
document.getElementById('rufusModeToggle')
```

**解决**: 刷新页面 (Ctrl+F5)

### 问题 2: 切换到 AI 模式后提示未配置

**检查**:
```javascript
localStorage.getItem('llm_active_provider')
```

**解决**: 在设置中配置 LLM 服务

### 问题 3: AI 模式失败自动降级

**检查控制台错误日志**:
- "未配置 LLM 服务" → 需要配置
- "LLM 配置不完整" → 检查 API Key
- "API Key 认证失败" → API Key 无效
- "网络请求失败" → 检查网络连接

### 问题 4: 看不到思考状态提示

**检查**:
1. 清除浏览器缓存
2. 硬刷新页面 (Ctrl+F5)
3. 检查 CSS 是否加载

### 问题 5: 控制台没有日志

**检查**:
1. Console 的日志级别设置
2. 是否启用了日志过滤
3. 刷新页面重试

## 验证成功标志

当您看到以下所有特征时，说明 AI 模式工作正常：

- ✅ 模式切换按钮显示 "🤖 AI 模式" (紫色)
- ✅ 思考过程显示三个阶段的状态消息
- ✅ 消息头部有 "🤖 AI 模式" 徽章
- ✅ 控制台有完整的 LLM 调用日志
- ✅ 回答内容更智能、更符合上下文
- ✅ 显示 "AI 回答生成成功" 的成功提示
