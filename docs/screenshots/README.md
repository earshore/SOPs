# 项目截图

`docs/screenshots/` 不再维护固定截图清单。历史截图和临时视觉验证图片应保存在被忽略的测试/审计输出目录中，例如 `tests/screenshots/`、`output/` 或 `tmp/`；只有需要长期随文档发布的图片才应放回本目录并同步更新本 README。

## 添加长期截图

1. 将截图文件放入 `docs/screenshots/`。
2. 使用 `{feature}-{description}.png` 这类稳定命名。
3. 在引用该截图的文档中使用相对路径。
4. 更新本 README 的截图索引。
