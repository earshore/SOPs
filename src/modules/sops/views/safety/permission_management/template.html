核心原则：最小权限 (Least Privilege)

员工仅获得完成工作所需的最小权限集合。Payments（结算）和Settings（账号设置）权限仅限Boss本人，任何情况不得下放。

Payments - 银行账户、提现、账单
Settings - 店铺信息、税务、用户权限

重要提醒

  • 员工离职时，立即删除其子账号（当天完成）
  • 每季度进行一次权限审计，清理不必要的权限
  • 岗位变动时及时调整权限范围
  • 主账号密码每90天强制更换

创建子账号步骤

  1. 1. Settings → User Permissions
  2. 2. 点击 "Add a New User"
  3. 3. 输入员工邮箱（公司邮箱）
  4. 4. 勾选对应权限模块
  5. 5. 发送邀请链接
  6. 6. 员工完成激活

权限变更归档输出

把新增用户、扩权、调岗、离职回收和季度审计沉淀成可追溯记录。
