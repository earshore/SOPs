1. 市场与选品优先级：先看真实需求，再决定站点

用 Product Opportunity Explorer 按站点查看搜索量、购买行为、评论痛点、定价区间、竞争饱和度和季节性。德国/英国适合先验证大盘需求，法国/意大利/西班牙要单独核对价格带与本地评价痛点，新兴站点优先找低饱和细分需求。

看什么 Search volume / price / reviews / returns
怎么做 按站点建立机会清单，标记需求、利润和合规风险
复盘 每月更新趋势，淘汰高饱和低转化机会

2. Listing 本地化：从翻译合格转向本地搜索可见

Amazon 要求跨站点详情页匹配当地语言。Build International Listings 可用于快速铺货，但核心 ASIN 应用本地搜索词、单位、尺码、日期、货币和图片文字重写，避免机器翻译造成关键词缺失或语义不自然。

看什么 SQP 查询词、Search Terms、竞品标题与评论措辞
怎么做 标题保核心词，五点写场景/参数/A+ 对比信息
复盘 看曝光、点击、加购、购买漏斗是否同步改善

3. 广告与 SEO 联动：用官方搜索漏斗做关键词分层

Search Query Performance 提供 ASIN 维度的曝光、点击、加购和购买数据；Sponsored Products Search Term Report 用来发现有点击的真实搜索词。把“高点击低购买”交给 Listing 优化，把“高购买低曝光”放入手动精准词，把“有花费无转化”加入否定。

看什么 CTR / CVR / cart add rate / search impression share
怎么做 自动广告采词，手动广告放量，否词控制浪费
复盘 周度看词级 ACOS、ROAS、自然排名和购买份额

4. 库存与促销节奏：把季节性需求接到补货计划

FBA Inventory / Restock Inventory 会结合销售历史、需求和季节性预测给出补货建议。旺季前不要只看广告预算，必须同步检查 90 天售罄节奏、库龄、断货风险、滞销清仓和目标站点 VAT/履约配置。

看什么 Sell-through / in-stock / aged inventory / restock
怎么做 旺季前 6-8 周锁定补货和 Coupon/Deal 排期
复盘 断货损失、库龄成本、促销后毛利和 IPI 风险

周度运营闭环

用同一套口径复盘欧洲各站点，避免只凭经验判断“哪个国家好卖”。

周一 更新 SQP / Search Terms，标记新增高潜词
周二 调整 Listing、A+、广告词和否词
周三 检查库存、补货、促销和合规阻塞
周五 用 MYE/Business Reports 判断改动是否放量
