# 自定义代理使用指南

## ui-ux-optimizer - UI/UX 优化专家

### 代理简介

`ui-ux-optimizer` 是一个专业的UI/UX优化代理，专注于Alpine.js + Tailwind CSS技术栈的界面交互优化。

**核心能力：**
- 交互设计优化：将复杂UI改造为零学习成本的直观交互
- 视觉设计：使用Tailwind CSS创建现代美观的界面
- 技术实现：精通Alpine.js和Tailwind CSS
- 可访问性：遵循WCAG 2.1 AA标准

### 使用场景

适用于以下UI组件的优化任务：
- 模态框和对话框
- 表单控件（输入框、选择器、滑块等）
- 下拉菜单和导航
- 卡片和列表组件
- 按钮和交互元素

### 如何使用

#### 方法1：通过主代理调用

在与Kiro对话时，可以要求主代理调用ui-ux-optimizer：

```
请使用 ui-ux-optimizer 代理帮我优化性能设置模态框中的最大并发数滑块
```

#### 方法2：直接指定代理

```
@ui-ux-optimizer 请帮我优化这个滑块组件，使其更直观易用
```

### 使用示例

#### 示例1：优化滑块控件

**需求：**
```
我需要优化性能设置模态框中的"最大并发数"滑块：
1. 当前是原生HTML range滑块，视觉效果一般
2. 希望添加刻度标记和说明文字
3. 需要即时显示当前值和预计效果
4. 保持与整体设计风格一致
```

**代理会提供：**
- 优化后的HTML结构
- 使用Tailwind CSS的样式实现
- Alpine.js交互逻辑
- 设计说明和用户体验改进点

#### 示例2：优化模态框

**需求：**
```
请优化这个设置模态框：
1. 添加更好的打开/关闭动画
2. 改进视觉层次和信息组织
3. 优化移动端显示效果
4. 确保键盘导航友好
```

### 最佳实践

1. **提供上下文**：告诉代理当前实现的问题和优化目标
2. **明确需求**：说明具体的功能需求和设计偏好
3. **提供代码**：如果可能，提供当前实现的代码片段
4. **迭代优化**：可以基于代理的方案进行进一步调整

### 技术栈要求

- **Alpine.js**：用于响应式数据绑定和交互
- **Tailwind CSS**：用于样式和布局
- **HTML5**：语义化标签和可访问性

### 输出内容

代理会提供：
1. **完整代码**：可直接使用的HTML + Alpine.js + Tailwind CSS代码
2. **设计说明**：关键设计决策和用户体验改进点
3. **使用指南**：集成步骤和注意事项（如需要）

### 注意事项

- 代理专注于Alpine.js + Tailwind CSS技术栈
- 如果项目使用其他框架，可能需要手动调整代码
- 代理会遵循WCAG 2.1 AA可访问性标准
- 所有代码都经过优化，确保性能和可维护性

### 反馈和改进

如果代理的输出不符合预期，可以：
1. 提供更详细的需求说明
2. 指出具体的问题点
3. 要求调整特定的设计元素
4. 请求替代方案
