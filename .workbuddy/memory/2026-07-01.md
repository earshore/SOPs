### 问题1三次修复（最终）：用专属 class 从根源避免冲突 ✅
- **用户反馈**：二次修复仍无效
- **调查方法**：用 Playwright headless 做实际渲染 + Computed Style 验证
- **发现**：隔离环境下二次修复的 CSS 规则确实生效（test-card 背景 rgba(255,255,255,0.1) ✓），但实际页面可能因 CSS 加载顺序或其他未追踪到的规则导致不生效
- **最终修复方案**：从根源避免冲突——用专属 class `ql-dark-tile` 替代 `bg-white bg-opacity-10`
  - HTML 模板：9处 `bg-white bg-opacity-10` 全部替换为 `ql-dark-tile`（行22/34-37/401/1525/1529/1534）
  - CSS：`.ql-dark-tile` 定义为 `background: rgba(255,255,255,0.1); color: #fff; border: 1px solid rgba(255,255,255,0.15)`
  - 关键优势：`ql-dark-tile` 不含 `bg-white` 类，通用卡片化规则（第35-50行 `.where(.bg-white, ...)`）完全不匹配它
  - 这不是靠 CSS 特异性"打赢"，而是从根源避免冲突
- **Playwright 验证**：test-card 背景 `rgba(255,255,255,0.1)` ✓，文字 `rgb(255,255,255)` ✓，amber 高亮 `rgb(252,211,77)` ✓
- **验证**：type-check + lint + 20个 smoke test 全部通过
