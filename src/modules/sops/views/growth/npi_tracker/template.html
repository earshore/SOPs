新品生命周期阶段

测款期 (0-30天)

上架后观察期。完成合规检查，启动Vine，测试广告响应。关键指标：CTR>0.5%，CVR有数据。

成长期 (30-90天)

积累评价、优化广告。目标：评分≥4.0，ACOS<40%，自然单占比提升。

稳定期 (90天+)

稳定出单，控制广告预算。目标：自然单占比>50%，利润率达标。

清仓期

库存周转>60天或持续亏损触发。降价至动销价或清仓红线止损。

上架前合规检查 (5项必做)

泛欧计划：确认是否启用Pan-EU，影响定价策略
Rufus优化：五点+标题包含场景词、解决痛点
敏感词：禁用侵权词、医疗声明、夸大宣传
图片+QA：主图白底、6张副图、常见QA预埋
A+页面：品牌故事+对比模块+场景展示

提示：合规状态显示✓表示全部通过，否则显示完成数/总数

"保留/放弃"决策标准

✓ 继续保留条件
  • • ACOS < 目标值 (通常40%)
  • • 评分 ≥ 4.0
  • • 自然单占比上升趋势
  • • 库存周转 < 60天
✗ 建议放弃条件
  • • 连续30天ACOS>60%且无改善
  • • 评分 < 3.5 且差评无法解决
  • • 库存周转 > 90天
  • • 售价已低于清仓红线仍无销量

各阶段详细 SOP 操作手册

测款期 (Day 0-30) 目标：验证产品是否有市场 & 完成基础建设

D0 上架日 Checklist

在本看板「基础档案」区录入 SKU/ASIN/店铺/站点/发货量
填写配送费 → 系统自动计算清仓线/动销价/建议价
完成5项合规Checklist（泛欧/Rufus/敏感词/图片QA/A+）
定价 = 市场均价 × 0.9，设置Coupon 5%-10%（吸引首单）
提交 Vine 申请（30个名额），备注提交日期
开启自动广告（竞价建议价×0.8），预算€10-15/天

D7 第1周：数据收集期

每日检查：广告曝光是否>100/天 → 否则检查Listing是否被抑制
确认ASIN是否已被亚马逊收录（搜索ASIN能找到自己）
检查Buy Box归属（新品偶尔会丢Buy Box）
记录本周流量/点击/订单基础数据到看板
7天后下载Search Term报告 → 收集有效搜索词

D14 第2周：广告优化期

从自动广告中提取出单词 → 开手动精准广告
否定无效关键词（高花费零转化的词，阈值：10次点击0单）
CTR<0.3% → 主图有问题，安排换图测试
CTR正常但CVR<8% → 检查价格/评论/五点是否有硬伤
Vine评价开始陆续到达 → 关注评分走势

D30 第3-4周：首次决策点

30天决策：此SKU是否进入成长期？
✓ 进入成长期：日均≥1单 + CTR>0.5% + 评分≥4.0
✗ 直接清仓：零单 或 评分<3.5 或 ACOS>80%无改善空间
△ 延长观察：有零星出单但数据不够 → 再给15天，期间不加预算
在看板「决策」栏更新：保留/放弃 + Next Step
成长期 (Day 30-90) 目标：积累评价 & 降低ACOS & 提升自然排名

广告策略

广告结构：自动(低竞价收词) + 手动精准(主推词) + 手动广泛(拓词)
每周否定一次无效词，周期：每周一执行
ACOS>50%的精准词 → 降竞价20% 或 暂停
出单好的词 → 开商品投放(ASIN定位)对标竞品
预算控制：日预算 = 日均销售额 × 目标ACOS

评价管理

Vine进度跟踪：目标30天内拿到15+评价
差评出现 → 48小时内联系买家(Buyer-Seller Message)
评分<4.0 → 检查产品缺陷，考虑改包装/说明书后重新发货
评分4.0-4.3 → 正常推进，加A+页面对比模块引导认知
评分≥4.3 → 可以开始提价至建议价

Listing优化

根据出单词优化标题（前80字符包含核心转化词）
根据差评优化五点（解决买家真实痛点）
补充后台Search Term（从广告报告中提取长尾词）
主图A/B Test（每2周测一次，至少跑7天数据）
价格策略：Day30-60保持新品价，Day60+逐步提至建议价

60天决策节点（成长期中期检查）

✓ 继续投入

ACOS<40% + 自然单占比≥30% + 日均≥3单 → 加大广告预算，备货第二批

△ 维持观察

ACOS 40-55% + 有自然单但不稳定 → 维持现状，不加预算，继续优化

✗ 准备退出

ACOS>55% + 评分<4.0 + 无自然单 → 降价至动销价，不再补货

稳定期 (Day 90+) 目标：最大化利润 & 降低广告依赖 & 补货节奏稳定

利润优化

价格提至建议价或以上（评分≥4.3可溢价5-10%）
广告预算逐步下调：每周降10%，观察自然单是否稳定
只保留ACOS<25%的精准词和品牌词广告
自然单占比目标：>50%（理想>70%）
Coupon/Deal策略：仅在大促期间使用（Prime Day/黑五）

库存管理

补货公式：(日均销量 × 补货周期天数) × 1.2安全系数
欧洲站补货周期预估：海运40天 + 上架7天 = 47天提前量
库存天数<30天 → 立即触发补货流程
库存天数>90天 → 考虑降价促销或跨站点调拨
旺季前60天 → 按日均销量×2备货

防御策略

每周监控竞品价格变动（3个核心竞品）
排名下降>20位 → 检查是否被恶意跟卖/差评攻击
品牌注册+透明计划（Transparency）防跟卖
定期更新A+页面和副图（每季度刷新一次）
考虑变体扩展（颜色/尺寸）复用评价权重
清仓期 目标：最小化亏损 & 尽快回笼资金

触发条件（满足任一即启动）

库存天数 > 90天，且降价后仍无明显改善
评分 < 3.5，差评问题无法通过改品解决
ACOS持续>60%超过30天，且已完成所有优化手段
品类竞争恶化，市场均价已低于自己的清仓红线
长期仓储费即将产生（FBA库龄>270天）

清仓执行步骤

① 立即停止所有广告投放，节省广告费
② 降价至动销价（清仓红线+€1），观察3天动销情况
③ 仍无动销 → 降至清仓红线，同时创建Outlet Deal
④ 评估是否创建移除订单（Removal Order）运回或销毁
⑤ 移除成本 vs 继续仓储成本对比，选择更低成本方案
⑥ 在看板标记「清仓完成」，归档至历史记录，记录亏损金额

新品定价

= 市场均价 × 0.9

低于市场价10%切入

清仓红线

= 配送费 ÷ 0.5

动销价格

= 清仓红线 + €1

欧洲站特别注意事项（踩坑总结）

VAT & 合规

• 泛欧计划(Pan-EU)：各国VAT号必须齐全，否则无法入仓

• EPR注册：DE/FR站必须有包装法合规注册号

• WEEE注册：电子产品必须，否则Listing会被下架

• CE认证：大部分品类需要，确保合规文件上传

多站点策略

• 首发站点选择：DE（最大）> FR > IT/ES > NL/SE/PL

• 同一ASIN泛欧后 → 只用改翻译即可多站点销售

• 小站点不单独开广告，靠泛欧自然流量测试

• 翻译质量：用母语者校对，机翻直接影响CVR

物流节奏

• 海运到DE仓：35-45天（含清关）

• 建议首批发货量：60-90天销量预估

• Q4旺季备货：最迟8月底海运出发

• 断货影响极大：排名恢复需2-3周

常见问题 FAQ（实操场景）

Q：新品上架多久没出单应该放弃？

A：30天是第一道红线。如果30天内曝光正常（>500/天）但零单，说明产品或价格有硬伤，建议直接清仓止损。如果曝光极低，先排查Listing是否有问题。

Q：Vine评价一直不来怎么办？

A：Vine评价通常7-21天开始到达。如果30天还没有，检查：①价格是否太低（Vine用户不感兴趣）②类目是否冷门 ③库存是否显示在售。无法解决就只能等自然评价。

Q：运营如何高效管理多个新品？

A：同时推广不超过5个新品。用本看板每周一复盘30分钟即可。严格执行阶段决策，不合格的果断清仓，不要拖。精力集中在有潜力的SKU上。

Q：清仓时应该降到什么价格？

A：分两步：先降到动销价（清仓线+€1），观察3天。如果仍无动销，直接降到清仓红线。低于清仓线卖每一单都在亏钱，这时考虑移除订单(Removal Order)可能更划算。

Q：如何判断该不该开泛欧？

A：默认开。除非：①该品类在小站点有合规风险（如电子产品需额外认证）②产品只适合特定市场（如德语书籍）。泛欧能显著降低配送费，提高小站点曝光。

Q：自然单占比一直上不去怎么办？

A：自然单占比低说明自然排名不够。检查：①核心关键词是否在标题前80字符 ②是否有足够评价（20+）③是否有A+页面 ④后台Search Term是否填满。如果以上都做了，可能是品类太卷，考虑换长尾词方向。
