# Prompt 生成页面 - 置信度功能用户指南

## 📖 功能概述

在 Prompt 生成页面，每个 AI 分析维度现在都会显示**置信度评分**，帮助您：
- 🎯 快速识别高质量的分析结果
- ✅ 选择置信度高的维度用于 Prompt 生成
- ❌ 避免使用低质量的分析数据

---

## 🎨 置信度显示

### 置信度徽章

每个分析维度的标题右侧会显示置信度徽章：

```
🔑 标题核心词根              [📊 93% 高]
💎 卖点结构拆解              [📊 93% 高]
⚠️ 致命缺陷                  [📊 37% 低]
```

### 颜色编码

- **绿色徽章** (≥70%) - 高置信度，推荐使用
- **黄色徽章** (50-69%) - 中等置信度，谨慎使用
- **橙色徽章** (<50%) - 低置信度，建议放弃

---

## 💡 置信度使用建议

**推荐工作流程**：
1. 完成 AI 分析后，导航到 Prompt 生成页面
2. 查看各维度的置信度评分（通过颜色徽章快速识别）
3. 优先选择高置信度（绿色）的维度
4. 谨慎使用中等置信度（黄色）的维度，建议人工审核
5. 避免使用低置信度（橙色）的维度
6. 生成 Master Prompt

---

## 💡 置信度等级说明

### 高置信度 (≥70%) 🟢
**含义**：分析结果质量高，数据完整，洞察可靠

**特征**：
- 数据来源充足（足够的评论或 Listing 信息）
- 分析结果详细完整
- 关键字段都有有效值

**建议**：✅ 推荐使用，可以放心纳入 Prompt

### 中等置信度 (50-69%) 🟡
**含义**：分析结果基本可用，但可能存在数据不足

**特征**：
- 数据来源有限
- 部分字段可能缺失
- 分析结果相对简略

**建议**：⚠️ 谨慎使用，建议人工审核后再纳入 Prompt

### 低置信度 (<50%) 🟠
**含义**：分析结果质量低，数据严重不足

**特征**：
- 数据来源极少（如只有 1-2 条评论）
- 大量关键字段缺失
- 分析结果过于简单或空泛

**建议**：❌ 不推荐使用，建议放弃或补充更多数据后重新分析

## 📊 实际案例

### 案例 1：高质量分析

```
✅ 🔑 标题核心词根              [📊 93% 高]
   Schlüsselanhänger, Sneaker, Turnschuh...

✅ 💎 卖点结构拆解              [📊 93% 高]
   主要差异化角度: 多功能性...

✅ ✨ Wow时刻                   [📊 100% 高]
   超出预期的具体瞬间...
```

**分析**：这些维度置信度都很高，可以全部选择用于 Prompt 生成。

### 案例 2：混合质量

```
✅ 🔑 标题核心词根              [📊 93% 高]
⚠️ 🤔 犹豫点                   [📊 55% 中]
❌ ⚠️ 致命缺陷                  [📊 37% 低]
```

**分析**：
- 标题核心词根：高质量，推荐使用
- 犹豫点：中等质量，建议人工审核
- 致命缺陷：低质量，建议放弃（可能是因为评论数据不足）

**建议操作**：
1. 启用"隐藏低置信度"筛选
2. 选择"标题核心词根"
3. 人工审核"犹豫点"后决定是否使用

## ❓ 常见问题

### Q1: 为什么某些维度置信度很低？

**A**: 常见原因：
- 评论数据不足（如只有 1-2 条评论）
- Listing 信息不完整
- 分析目标不适用于该产品（如"致命缺陷"但产品评价都很好）

**解决方法**：
- 采集更多评论数据
- 补充完整的 Listing 信息
- 放弃不适用的分析维度

### Q2: 低置信度的分析结果能用吗？

**A**: 不推荐使用，原因：
- 数据不足导致分析不准确
- 可能包含错误或误导性信息
- 影响最终 Prompt 的质量

**建议**：优先使用高置信度的分析结果。

### Q3: 如何提高置信度？

**A**: 提高数据质量：
1. 采集更多评论（建议至少 10+ 条）
2. 确保 Listing 信息完整（标题、五点描述等）
3. 选择适合产品的分析维度
4. 使用高质量的数据源

### Q4: 筛选功能会影响已选择的维度吗？

**A**: 不会。筛选只影响显示，不会自动取消已选择的维度。

## 🎯 最佳实践

### 1. 数据质量优先
- 始终优先使用高置信度的分析结果
- 低置信度的数据宁可不用，也不要误用

### 2. 合理使用筛选
- 对于大量分析维度，使用筛选快速定位高质量数据
- 不要完全依赖筛选，人工审核仍然重要

### 3. 结合实际情况
- 置信度是参考指标，不是绝对标准
- 结合产品实际情况和业务需求做判断

### 4. 持续优化
- 根据置信度反馈，优化数据采集策略
- 补充低置信度维度的数据源
