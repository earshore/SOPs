Step 2: 大货验货 (AQL抽检)

按AQL标准随机抽检

  • • 外观检查：划痕、变形、色差
  • • 功能测试：开关、充电、尺寸
  • • 安全检查：锐边、小零件、警示

Step 3: 包装跌落测试

模拟运输冲击

  • • 1米高度 角跌落 ×1 次
  • • 1米高度 棱跌落 ×2 次
  • • 1米高度 面跌落 ×3 次
  • • 开箱检查产品完好性

Step 4: 入库前检查

贴标与配件检查

  • • FNSKU标签正确且可扫描
  • • 原有条形码已覆盖
  • • 配件/说明书齐全
  • • 包装完好无损

Step 5: 出具QC报告

验收结论与归档

  • • 填写QC报告表
  • • 拍摄产品/缺陷照片
  • • 给出验收结论

缺陷等级分类

致命缺陷 (Critical) AQL 0

安全隐患、法规不符 → 零容忍，整批拒收

主要缺陷 (Major) AQL 1.0

功能故障、明显外观问题 → 严格控制

次要缺陷 (Minor) AQL 2.5

轻微外观瑕疵不影响使用 → 允许少量
