# PC 端 UI 优化方案概览

## 已完成

- 按用户要求重新聚焦 PC / 桌面端场景，排除了移动端导航、小屏触控、窄屏卡片换行等优化重点。
- 输出了新的 PC 端 UI 优化方案，覆盖桌面布局节奏、设计令牌、应用中心卡片、设置面板、模态框、导航、表格列表、交互反馈和可访问性。

## 关键调整

- 优先级从“全端适配”调整为“PC 工作台效率”。
- 必须改进项聚焦：令牌收敛、PC 页面布局节奏、应用中心卡片交互语义、设置面板双栏化、模态框主题令牌化。
- 建议优化项聚焦：顶部导航当前位置感、应用中心紧凑视图、表格/列表扫描规格、统一 Hover/Focus/Active、减少 `transition: all`、任务导向空状态。
