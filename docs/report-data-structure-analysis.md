## Recommendations for DNA Extractor Implementation

### 1. Multi-Report Aggregation
The DNA extractor should:
- Accept multiple report files as input
- Identify report type by structure (presence of specific fields)
- Merge data intelligently across report types
- Deduplicate keywords and phrases
- Prioritize semantic analysis for natural language

### 2. Field Mapping Strategy
Create a unified schema that maps:
- `intent` → `intents` (normalize to plural)
- `keyword_clusters` ↔ `keywordClusters` (handle both)
- `compliance_risks` ↔ `complianceRisks` (handle both)
- Top-level vs nested `user_profile` (context-aware)

### 3. Confidence Scoring
Assign confidence scores based on:
- **High confidence**: Present in multiple reports
- **Medium confidence**: Present in single authoritative report (semantic/product analysis)
- **Low confidence**: Inferred or derived data

### 4. Category-Specific Extraction
Some fields are category-specific (e.g., `flightCharacteristics` for toys). The extractor should:
- Identify category from `productOverview.category` or `product_summary`
- Apply category-specific extraction rules
- Store category-specific data in flexible structure

### 5. Validation Rules
- Ensure all P0 fields are extracted (fail if missing)
- Validate keyword arrays are non-empty
- Check compliance risks are addressed
- Verify technical specs contain measurable data

## Appendix: Report Type Detection Logic

```typescript
function detectReportType(report: any): ReportType {
  // Copywriting report
  if (report.seo_title && report.bullet_points && report.product_description) {
    return 'copywriting';
  }

  // Negative review report
  if (report.top_quality_issues && report.customer_complaints && report.improvement_suggestions) {
    return 'negative';
  }

  // Semantic analysis report
  if (report.native_voice && report.pain_point_gaps) {
    return 'semantic';
  }

  // Product analysis report (extended)
  if (report.productOverview && report.coreFeatures && report.user_profile) {
    return 'product_analysis';
  }

  // Competitor analysis report (standard)
  if (report.competitor_insights && report.keyword_clusters) {
    return 'competitor';
  }

  return 'unknown';
}
```
