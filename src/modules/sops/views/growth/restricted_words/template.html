为什么这是你最需要重视的 SOP — 没有之一

🚫 Listing 被下架
使用违规词 → 亚马逊系统自动扫描 → Listing 立即被抑制(Suppressed)。恢复最快 3-7 天，最慢数周。期间零销售、广告白烧、排名暴跌。
💰 库存滞留 + 资金冻结
Listing 下架期间，FBA 库存产生长期仓储费，但你无法销售。严重违规还会冻结账号资金 90 天。
⚖️ 欧洲法律处罚
欧盟法规不是亚马逊的规定——是法律。虚假声明（如伪造 CE 标志）在德国可罚款 €50,000+。GPSR 2024 年新规更加严格。
☠️ 账号被关
累积多次违规/涉及安全声明/伪造认证 → 账号永久关闭。一人公司 = 全部身家在一个账号上，这是致命风险。
真相：很多中国卖家在欧洲站被封不是因为刷单/黑帽，而是因为Listing 文案中用了一个不该用的词。 "antibacterial""medical grade""organic"——这些在其他市场看似常见的表达，在欧洲可能直接触发法规风险。

风险等级定义 — 5 级分类

5
致命 · FATAL
绝对禁用。
使用即触发下架/审查/封号。无任何合规文件可救。
例：伪造 CE 标志、虚假医疗声明
4
严重 · HIGH
需持证使用。
必须有对应合规文件（检测报告/认证）才能使用。无证即违规。
例：CE (需DoC)、EN71 (玩具)
3
中等 · MEDIUM
有条件使用。
需要特定资质/认证，或需要修改措辞后才可使用。
例：Organic (需 EU Bio 认证)
2
注意 · CAUTION
建议替换。
不一定立即触发违规，但存在被投诉/审查的风险。有更安全的替代词。
例：Eco-friendly (模糊声明)
1
提醒 · INFO
需注意措辞。
本身不违规，但在特定语境/品类下可能引起问题。
例：Professional (暗示专业用途)

Listing 发布前合规检查流程 — 每次必做

不只是新品上架——每次修改标题/Bullet Points/描述/A+内容/后台Search Terms时，都必须走一遍。

1

文案全文自查

  • • 将你的标题 + 5 条 Bullets + 描述 + A+ 文字 + Search Terms 全部复制出来
  • • 在下方词库搜索框中逐一检索核心卖点词
  • • 重点检查：材质词、功能声明词、安全认证词、健康声明词
  • • 每种语言版本都要查（DE/FR/IT/ES 各查一遍）
  • ⏱ 预计耗时：5-10 分钟/ASIN
2

风险评估 + 决策

  • • 命中词条 → 查看风险等级
  • • 5级：立即删除，无商量
  • • 4级：你有合规证书吗？有→保留；没有→删除或替换
  • • 3级：查看替代词方案
  • • 2-1级：建议替换，不强制
3

替代修正 + 发布

  • • 查看词条详情中的安全替代词
  • • 修改文案，确保替代后语义通顺
  • • 替代词也要在词库中搜索一次（避免替代词本身也有风险）
  • • 确认无误 → 发布/更新 Listing
  • • 发布后 24h 再检查 Listing 状态是否正常
4

合规文件归档

  • • 使用了 4 级词（持证使用）→ 确认合规文件已上传后台
  • • 文件类型：DoC（符合性声明）、测试报告、认证证书
  • • 检查证书有效期（很多 EN71/REACH 报告有效期 1-2 年）
  • • 归档到产品合规文件夹（本地 + 网盘双备份）
  • • 设日历提醒：证书到期前 60 天续办

EU 核心法规速查 — 知道你在面对什么

你不需要成为法律专家，但必须知道每条法规管什么、违反了什么后果。以下是影响 Listing 文案最大的法规。

2024新规

GPSR 通用产品安全法规

  • 管什么：所有消费品的安全信息标注
  • 要求：Listing 必须显示 EU 授权代表信息、制造商信息
  • 影响文案：不能随意声明安全性，不能用"100% safe"等绝对措辞
  • 生效：2024年12月13日起强制执行
  • ⚠ 这是2024-2025最大的合规变化
核心

CE 标志 / UKCA

  • 管什么：电子产品/玩具/PPE/医疗器械等必须有 CE 标志
  • 影响文案：不能在文案中声明 CE 除非你真的有 DoC
  • 常见雷区："CE certified"需要你有实际的符合性声明(DoC)
  • GB特殊：UKCA 与 CE 认可口径按当前英国政府指南和品类法规复核
  • 伪造 CE 标志 = 刑事犯罪(德国)
玩具

EN71 玩具安全指令

  • 管什么：所有面向 14 岁以下儿童的产品
  • 影响文案：产品暗示或明示给儿童用 → 触发玩具分类
  • 危险词："for kids""children""toy""educational"
  • 注意：即使你不卖玩具，用了这些词也可能被归为玩具类
  • 一旦被归为玩具 → 必须提供 EN71 报告
化学

REACH 化学品法规

  • 管什么：产品中的化学物质含量（SVHC 高关注物质）
  • 影响文案："chemical-free""non-toxic"等声明需有检测支持
  • 常见雷区：声明"BPA-free"需要实际 REACH 检测报告
  • 注意：2024 SVHC 清单已更新至 240+ 种物质
标签

CLP 分类标签和包装法规

  • 管什么：含化学成分的产品（清洁剂/香薰/精油等）
  • 影响文案：不能用"natural""safe""gentle"等误导性词描述化学品
  • 要求：必须显示 GHS 危险标志和安全说明
  • 常见雷区：精油/蜡烛/清洁用品
纺织

EU 纺织品标签法规

  • 管什么：所有纺织品的成分标注
  • 影响文案："Bamboo fiber"在 EU 必须标为"Viscose"
  • 著名雷区："100% Bamboo"→ 违规！正确写法是"100% Viscose (from Bamboo)"
  • 注意：成分百分比必须精确标注
  • 竹纤维是被罚最多的违规之一
食品接触

FCM 食品接触材料法规

  • 管什么：与食品接触的产品（餐具/水杯/厨具/保鲜盒）
  • 影响文案："Food-grade"声明需有 LFGB (DE) / Décret (FR) 检测
  • 危险词："Food safe"需要实际食品接触测试报告支持
  • 注意：竹纤维/三聚氰胺餐具在EU部分国家已被禁止
杀菌

BPR 杀菌产品法规

  • 管什么：任何声称有杀菌/抗菌功能的产品
  • 致命词汇："Antibacterial" "Antimicrobial" "Kills 99.9% germs"
  • 后果：未经 BPR 注册的杀菌声明 → 直接下架 + 可能罚款
  • 注意：即使产品确实含抗菌成分，没有 BPR 注册也不能写
  • 这是中国卖家踩雷最多的法规
医疗

MDR 医疗器械法规

  • 管什么：任何暗示医疗/治疗/诊断功能的产品
  • 致命词汇："Treat" "Cure" "Heal" "Medical grade" "Therapeutic"
  • 后果：产品被归为医疗器械 → 需要 MDR Class I+ 认证
  • 常见雷区：按摩器/护膝/矫正带/蓝光眼镜
  • 一旦被归为医疗器械几乎无法解除

最常踩雷 TOP 20 — 中国卖家欧洲站被处罚频率最高的词

以下是实战中被Listing抑制/要求提供合规文件频率最高的词汇。先把这 20 个记住，就能避免 80% 的合规风险。

1
Antibacterial / Antimicrobial 5级

需 BPR 杀菌产品注册。替代→ "Hygienic design" "Easy to clean"

2
Medical Grade / Surgical 5级

触发医疗器械法规。替代→ "Premium quality" "Professional grade"

3
Bamboo / 100% Bamboo 4级

纺织品法规：竹纤维必须标为 Viscose。替代→ "Viscose (from Bamboo)"

4
Organic 4级

EU 有机认证法规，需 EU Organic 标志。替代→ "Natural" "Made from natural materials"

5
CE Certified / CE Approved 4级

需有实际 DoC。"CE" 不是认证而是合规标志，写"CE approved"在法律上就是错的

6
Cure / Treat / Heal / Therapy 5级

医疗声明绝对禁止。替代→ "Supports" "Helps with comfort" "Promotes relaxation"

7
For Children / Kids / Toy 4级

触发EN71玩具分类。如果不是玩具→删掉。替代→ "Suitable for all ages" (仍需注意)

8
BPA-Free / Non-Toxic 3级

需有REACH检测报告支持。没有报告→不要写。替代→ "Made from [specific safe material]"

9
FDA Approved 5级

FDA 是美国机构，在欧洲没有法律意义。在 EU 使用 = 误导消费者 → 下架

10
Eco-Friendly / Green / Sustainable 3级

EU Green Claims Directive。无具体证据的环保声明将被禁止。替代→ 具体描述："Made from recycled materials"

11
Kills 99.9% (Germs/Bacteria/Virus) 5级

杀菌功效声明，需 BPR 注册。绝对不用！

12
Clinically Tested / Proven 5级

需有实际临床数据支持。虚假声明 → 欧洲消费者保护法处罚

13
Waterproof (IPX 未标注等级) 3级

声明防水需标明 IP 等级。替代→ "Water-resistant (IPX4)" 带具体等级

14
Leather / Genuine Leather / Leder 4级

德国/EU 严格定义真皮。PU/人造革写 Leather → 欺诈。替代→ "PU Leather" "Faux Leather"

15
Stainless Steel (无标号) 2级

德国买家会质疑具体型号。建议标注"304 Stainless Steel" / "18/10"

16
Anti-Cancer / Prevents Disease 5级

最高级别违规。任何疾病预防/治疗声明绝对禁止。

17
Made in Germany/Italy (虚假原产) 5级

虚假原产地声明 = 消费者欺诈。中国制造就写 "Made in China" 或不写。

18
Hypoallergenic 3级

需有皮肤测试报告支持。替代→ "Dermatologically friendly" (仍建议有测试支持)

19
TÜV / GS Certified 4级

TÜV/GS 是德国安全认证，冒用是严重违规。有证才能写，且需标注报告编号。

20
100% Safe / Absolutely Safe 3级

绝对安全声明无法证实。GPSR 不允许。替代→ "Designed with safety in mind" "Meets EU safety standards"

品类专项雷区 — 按你的产品类目检查

厨房/餐具用品

  • 🚫 Food grade → 需 LFGB/1935:2004 报告
  • 🚫 BPA-free → 需 REACH 检测
  • 🚫 Bamboo tableware → 竹纤维+三聚氰胺餐具 EU 禁售
  • ⚠️ Dishwasher safe → 需实际测试证明
  • ✅ 安全替代："Meets EU food contact standards (with certificate)"

纺织品/服装

  • 🚫 100% Bamboo → 必须标 "Viscose"
  • 🚫 Organic Cotton → 需 GOTS/EU Organic 认证
  • 🚫 Leather → 人造革不能用此词
  • ⚠️ Silk → 如果不是真丝要标注 "Satin" 等
  • ✅ 安全替代："Viscose from bamboo" "OEKO-TEX certified"

电子产品

  • 🚫 CE Certified → 正确写法 "CE marked (DoC available)"
  • 🚫 GS 标志 → 冒用 = 德国刑事犯罪
  • ⚠️ Waterproof → 必须标 IP 等级
  • ⚠️ Universal voltage → 欧洲是 220-240V，需标明
  • ✅ 必备：WEEE 注册号 / 包装法注册 / DoC

儿童/婴幼儿用品

  • 🚫 Toy / For kids → 触发 EN71
  • 🚫 Educational → 同样触发玩具分类
  • 🚫 Non-toxic paint → 需 EN71-3 测试
  • ⚠️ Age 3+ → 必须有对应年龄段安全测试
  • ✅ 核心：EN71-1/2/3 + REACH + 包装法缺一不可

美容/个护/香薰

  • 🚫 Anti-aging / Anti-wrinkle → 化妆品法规限制声明
  • 🚫 Dermatologically tested → 需实际皮肤测试报告
  • 🚫 Aromatherapy → 暗示治疗功效
  • ⚠️ Essential oil → CLP 标签义务（GHS 标志）
  • ✅ 精油/蜡烛必须有 MSDS + CLP 标签

运动/健康/保健

  • 🚫 Orthopedic / Medical → 触发 MDR
  • 🚫 Relieves pain / Treats → 医疗声明
  • 🚫 Posture corrector → 可能被归为医疗器械
  • ⚠️ Supports / Helps with → 擦边但相对安全
  • ✅ 安全替代："Designed for comfort" "Ergonomic design"

已上架 Listing 紧急排查指南

如果你的 Listing 已经上架了一段时间但从未做过合规检查——现在就做。不要等到被亚马逊抑制才补救。

🔍 紧急排查步骤

  • 1. 导出所有 ASIN 的标题+Bullets+描述（后台 Inventory → 下载）
  • 2. 用 Ctrl+F 搜索上方 TOP 20 高危词的英语版
  • 3. 再用各语言版本搜索（DE/FR/IT/ES）
  • 4. 命中的词条标红记录到排查表
  • 5. 按风险等级从高到低修正（5级最先处理）
  • 6. 修改后检查 Listing 状态是否正常（24h内）

🚨 Listing 已被抑制怎么办

  • 1. 后台 Inventory → Listing Quality → 查看抑制原因
  • 2. 根据原因定位是哪个词/声明触发的
  • 3. 删除或替换违规内容
  • 4. 如果要求提供合规文件 → 上传对应证书
  • 5. 重新提交 Listing → 等待审核（通常 24-72h）
  • 6. 未恢复 → 开 Case 说明已修正，提供证据
  • 7. 被要求提供你没有的证书 → 考虑永久删除该声明词

2024 新规 GPSR 通用产品安全法规 — 对 Listing 的影响

GPSR 对文案的新要求

  • • Listing 上必须显示制造商名称和地址
  • • 必须显示EU 境内授权经济运营商（如果制造商在EU境外）
  • • 产品安全信息不能过度声明（"100% safe" 等绝对措辞被禁）
  • • 产品安全警告和使用限制必须清晰标注
  • • 如果亚马逊认为产品信息不完整，可以直接下架

一人公司合规检查时间规划

📅 每次上新品（10 分钟）

  • • 对照高危词库检查 Listing 文案
  • • 所有语言版本都过一遍
  • • 确认合规文件已上传
  • • 上架后 24h 检查 Listing 状态

📅 每季度（30 分钟）

  • • 全量扫描所有在售 ASIN 的 Listing
  • • 检查证书有效期
  • • 关注法规更新（SVHC 清单/新指令）
  • • 更新本地高危词库（如有新发现）

📅 收到合规通知时（立即）

  • • 亚马逊发来合规审查通知 → 最高优先级
  • • 24h 内响应（提交文件或修改 Listing）
  • • 没有证书 → 立即删除违规声明
  • • 问题解决后排查同品类其他 ASIN

合规工具 & 资源

认证检测机构

  • • TÜV / SGS / BV（常规 CE/EN71/REACH）
  • • Intertek（纺织品/食品接触）
  • • 国内：CTI 华测 / SGS 中国 / BV 中国
  • • 费用参考：EN71 约 ¥3000-5000/产品

EU 授权代表服务

  • • GPSR 要求非 EU 卖家有 EU 境内代表
  • • 服务商：Compliance Gate / ProductIP
  • • 亚马逊自有服务：Amazon Compliance Reference
  • • 费用参考：€200-500/年

法规查询

  • • EUR-Lex（EU 法规原文）
  • • Safety Gate (RAPEX)（产品召回查询）
  • • 亚马逊后台 → Help → Product Compliance
