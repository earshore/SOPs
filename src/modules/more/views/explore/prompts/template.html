输入数据先行
输出可验收
人工复核闭环

先给证据

关键词库、搜索词报表、竞品页、评论原文先进入上下文；模型不负责猜实时市场数据。

任务要单点

一次只让模型完成一个清晰目标：改标题、分诊PPC、审声明或写回复，避免万能提示词失控。

先定输出

提前要求表格、清单、风险分级和复查时间，减少长篇空话，让结果能直接进入SOP。

复用前评估

关键提示词至少用正常、缺数据、边界和高风险样本跑一轮，再沉淀为团队模板。

Prompt Formula

运营提示词公式

先把业务问题工程化，再让模型生成内容。

COPYABLE STRUCTURE
  1. 1. 角色：你是谁，负责什么，不负责什么。
  2. 2. 目标：本轮只解决一个业务问题。
  3. 3. 输入：粘贴真实数据，并标注来源和时间范围。
  4. 4. 约束：禁止猜测、禁止夸大、缺数据要说不知道。
  5. 5. 步骤：让模型先分类、再判断、最后给动作。
  6. 6. 输出：表格、清单、优先级、负责人、复查指标。
  7. 7. 自检：列出证据不足、合规风险和人工复核点。

上线前五问

  • 是否用了真实数据，而不是让模型编市场事实？
  • 输出是否能被运营直接执行？
  • 是否有合规、费用、政策的人工复核点？
  • 缺数据时模型是否会拒绝下结论？
  • 是否有小样本评估和复查标准？

不再做的事

不要让模型“帮我写一个爆款Listing”。改成：基于关键词库、竞品页、评论痛点和产品证据，按指定输出结构生成可审稿初稿。

Seller Playbooks

四条高频实战路径

从数据到动作，提示词只负责中间的判断与组织。

Listing转化

关键词库 + 竞品页 + VOC -> 标题、五点、A+结构和合规自检。

输入：关键词、竞品、评论痛点
处理：意图分组、卖点排序
输出：可审稿文案和风险项

PPC分诊

搜索词报表 + 毛利约束 -> 加词、否词、降价、预算和Listing承接问题。

输入：点击、花费、订单、ACOS
处理：样本量和目标分桶
输出：保守/激进动作表

VOC闭环

评论、QA、退货原因 -> 产品改进、Listing预期管理、客服话术。

输入：原始评价和时间范围
处理：主题聚类和严重度
输出：责任方行动地图

合规风控

标题、五点、A+、图片文案 -> 声明分类、证据链和安全改写。

输入：文案、证书、类目规则
处理：声明分级和证据检查
输出：风险表和替代表达

Business Operating Rules

业务规则如何进入提示词

把平台规则、搜索数据、广告报表和卖家工具实践内化为提示词的输入、边界和验收动作。

Listing规则 先合规，再转化

标题、五点、描述和图片文案必须围绕同一商品事实展开，禁用促销语、夸大声明、无证据认证和与商品无关的信息。

提示词要求

输入产品事实、禁用词、证据文件；输出文案时同步列出“可上线 / 需证据 / 不建议写”的字段。

关键词口径 从词库到搜索意图

关键词不是直接塞进标题，而要先按核心词、属性词、场景词、问题词、竞品替代词分组，决定放在标题、五点、A+或后台词。

提示词要求

要求模型先分组、再分配位置，不能用搜索量、销量、排名等未提供数据做判断。

搜索漏斗 按查询表现定优先级

Search Query Performance 这类漏斗数据用于看查询、曝光、点击、加购和购买差异，提示词要识别“有搜索没点击”和“有点击没转化”的不同问题。

提示词要求

输出关键词优先级、页面承接缺口和需要补图/补卖点/调价格的验证项。

广告报表 搜索词报表只给事实，不给冲动动作

PPC动作必须基于点击、花费、订单、销售额、ACOS/ROAS和样本量。低样本只能观察，不能直接否词或大幅调价。

提示词要求

区分加词、否词、降价、提预算、Listing承接差；每个动作写触发依据、风险和复查时间。

VOC闭环 评论不是情绪总结，是责任分发

评论、QA、退货和客服工单要先聚类，再拆给产品、Listing、客服和合规。能改文案的马上改，涉及产品缺陷的必须验证。

提示词要求

每条洞察必须带原始证据、严重度、责任方、行动项和验证方式，避免“客户不满意”式空结论。

竞品拆解 学结构，不抄表达

竞品详情页拆解关注页面叙事、图片顺序、价格带、评论痛点和信任证据；不复制竞品品牌词、夸大声明或可能侵权的素材。

提示词要求

输出“可跟进打法”和“不建议模仿风险”，并把机会落到标题、图片、A+、广告词或产品改进。

合规证据链 声明必须能被证明

环保、认证、防水、抗菌、医疗、安全、质保、比较级等声明必须对应证书、测试报告、包装说明或类目要求。

提示词要求

模型只能做风险分级和改写建议；无法确认的法规、类目和IP问题必须标记人工复核。

转化验证 好文案要进入实验

标题、主图、五点、描述和A+内容的优化结论，最终要用转化率、点击率、加购率、CVR或实验结果验证。

提示词要求

输出假设、改动位置、观察指标、复查周期和回滚条件，避免一次生成就直接固化。

AI角色边界 模型是分析助理，不是决策负责人

模型负责整理证据、提出候选动作、发现缺口和生成草稿；预算、价格、合规、账号风险和供应链动作由负责人复核。

提示词要求

每个模板都要包含“不得猜测数据”“需要人工确认”“上线前验收标准”三类约束。

01 数据包

关键词库、广告报表、评论原文、竞品页、证书、成本和库存约束。

02 模型任务

分类、诊断、草拟、风险标注、行动排序，不负责凭空补市场事实。

03 人工复核

运营、广告、产品、客服、合规按责任边界确认是否执行。

04 业务回写

把动作、指标、复查时间和结论沉淀回模板，形成下一轮提示词迭代。
