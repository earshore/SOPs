Business Basis

归纳依据

按业务对象、经营阶段、决策动作和风险边界归纳，而不是按页面名称简单归类。

业务对象

围绕 ASIN、Listing、广告活动、库存、评论、QA、绩效通知和合规资料组织流程。

经营阶段

覆盖选品上架、新品冷启动、广告投放、转化优化、补货、售后和风险处置。

决策动作

输出可执行动作：改文案、补词、否词、调预算建议、补货提醒、回复草稿和升级路径。

风险边界

价格、预算、广告暂停、绩效回复、合规申诉和后台权限必须保留人工审批。

Business Audit

核心业务链路审计

先看经营目标和岗位动作，再映射到已有页面承接。

增长闭环

围绕新品、Listing、关键词、PPC、促销和竞品监控，目标是把流量、转化和广告动作标准化。

经营数据到运营决策链

采集和分析不是目的，最终要服务竞品判断、关键词补强、广告动作、Listing 改版和复盘汇报。

客户声音闭环

差评、QA、邮件模板和评论监控沉淀 VOC，反向驱动 Listing 表达、质检和供应链改进。

风控与晨会链路

账号安全、权限、合规、绩效通知和一键日报共同构成“先暴露风险，再进入人工处置”的经营安全层。

Listing 改版工作流

竞品采集 -> AI 洞察 -> Prompt 生成 -> SEO 与高危词复核。

高频
输入

目标 ASIN、竞品 ASIN、核心词、站点和类目。

产出

标题、五点、A+ Brief、埋词说明和风险词清单。

确认点

发布前人工确认合规、卖点真实性和移动端可读性。

PPC 搜索词周优化

报表导入 -> 规则初判 -> 模型复核 -> 动作清单 -> ERP / 广告后台执行。

已原型
输入

Amazon Ads 搜索词、ERP 搜索词或广告活动报表。

产出

否精准、加精准、加预算、降竞价和 Listing 词池建议。

确认点

高花费、低置信和品牌词必须人工复核后再执行。

新品 30 天突围节奏

上架准备 -> 定价与库存 -> Listing 完成度 -> 促销节点 -> 广告复盘。

增长
输入

新品成本、配送费、目标毛利、首批库存和上架日期。

产出

清仓线、动销价、建议价、30 天动作表和复盘清单。

确认点

促销前核算折后利润，广告预算按库存承接能力调整。

VOC 质量反馈闭环

差评 / QA / 邮件 -> 问题归类 -> 回复草稿 -> 产品与质检反馈。

服务
输入

新差评、QA 未回复、售后邮件、退换货原因和产品批次。

产出

回复草稿、VOC 分类表、供应链反馈和 Listing 修订建议。

确认点

客服回复遵守平台规则，质量问题先确认批次与证据。

合规上架与风险巡检

产品合规 -> GPSR -> 品牌侵权 -> 权限与绩效 -> 处置登记。

风控
输入

类目、材质、认证、品牌词、图片素材和绩效通知。

产出

风险等级、证明材料清单、整改建议和升级路径。

确认点

高风险事项禁止模型直接回复后台，必须由负责人审批。

店铺晨会日报

销售、库存、FBA、广告、口碑和合规按优先级汇总。

经营
输入

店铺、站点、时区、销售报表、广告概览和绩效提醒。

产出

晨会摘要、红黄提醒、取数状态和待处理动作。

确认点

失败模块必须显式展示，货件差异和绩效升红优先提醒。

Standard Pattern

标准编排骨架

1. 触发

手动、周报、晨会前、促销前或绩效通知出现时触发。

2. 输入

站点、ASIN、报表、阈值、负责人和时间窗口必须明确。

3. 承接

把业务动作映射到已有页面：采集、分析、PPC、关键词、智库和 SOP。

4. 模型

只处理归纳、复核、草稿和异常解释，不直接执行高风险动作。

5. 审批

价格、广告、合规、后台回复和权限动作保留人工确认。

6. 沉淀

保留版本、字段映射、失败记录、产出链接和下次复盘项。

优先上线

业务频率高、动作边界清晰、现有页面可承接。

  • Listing 改版工作流
  • PPC 搜索词周优化
  • 店铺晨会日报

人工审批边界

自动化只到建议和草稿。

  • 不自动改价、加预算或暂停广告。
  • 不自动回复绩效通知或高风险客服消息。
  • 不把低置信模型结论直接写入 SOP。

复盘口径

每次执行后能继续优化。

  • 记录输入报表版本、字段映射和失败模块。
  • 动作清单标注负责人、截止时间和处理状态。
  • 规则变化进入版本记录，避免单站补丁漂移。
