# Amazon 2026 商品名称合规设计

## 目标

根据 `docs/【新规】商品名称要求和指南.pdf`，把商品名称规则落地为可验证、可解释的规则服务，并同步生成提示词、粘贴文案辅助提示和运营文档，避免把 75 字符误用为全局规则。

## 规则边界

- 新规适用于除 SA、EG、TR、AE 外的商城，媒介类商品除外；目标场景是首次发布商品。
- 适用场景下标题最多 75 个字符（含空格）；商品亮点是独立字段，最多 125 个字符，用逗号分隔短语。
- 促销语、受限 FSA/HSA 短语、固定禁用特殊字符和超限重复词是确定性错误。
- `~ # < > *` 只有在商品编码或测量上下文中允许；必要的 `- / , & .` 不作硬错误。
- 信息顺序、大小写、父子 ASIN 属性和亮点短语格式属于可解释的 warning，不能伪装成全类目硬性型号规则。
- SA/EG/TR/AE 与媒介类在请求 v2 时回退到 v1 基线，不使用本 PDF 没有依据的 50 字符硬限制。

## 接口设计

`TitleComplianceInput` 增加：

- `isFirstPublication?: boolean`：明确标识首次发布；省略时仅在显式请求 v2 时按适用处理，存量调用可传 `false`。
- `asinRole?: 'parent' | 'child'` 和 `variationAttributes?: { color?: string; size?: string }`：仅在有上下文时检查父子变体建议。
- `highlights?: string`：校验独立商品亮点的 125 字符上限和句式提示。

规则服务继续保持纯函数；`appliedVersion` 返回实际执行的版本，豁免场景返回 v1。错误结果只表示校验不通过，不自动阻止已有数据。

## 运行入口

- PromptLab v2 文案修正为允许计量单位缩写、补充完整 FSA/HSA 受限短语说明，并保留显式 v1/v2 选择。
- Deep Chat 与 Keyword Hunter 复用统一标题提取器；提取失败显示“未识别标题”，不把空标题当作通过。
- 真实商品发布字段的最终阻止/提交策略留给调用方；本次服务提供完整报告和上下文，而不是从任意整段 Listing 猜测后强行拦截。

## 验收

- 规则单测覆盖适用/豁免、FSA/HSA 变体、字符上下文、亮点、父子 ASIN 和 Unicode 计数。
- PromptLab 单测确认单位缩写允许、FSA/HSA 被禁止。
- 文档不再声称 2026-07-27 是 PDF 给出的生效日，不再把 `&` 当作固定禁用字符。
