## 如何更新

1. 发现债 → 新增一行 Open（含 ID、领域、影响、建议、证据）。
2. 修复 → 移到 Closed（日期 + PR/commit）。
3. 发版前扫一眼 P0/P1。
4. 与规范冲突时：**先改规范或先改板，禁止双真相。**
