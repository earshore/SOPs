## 🔧 自动化工具

### 批量替换脚本
**文件**: `scripts/batch-replace-any.ts`

**功能**:
- 扫描所有 TypeScript 文件
- 应用预定义的替换规则
- 跳过注释和字符串中的匹配
- 生成详细的替换报告

**使用方法**:
```bash
# 预览模式（不修改文件）
npm run batch-replace-any:dry

# 仅应用安全规则
npm run batch-replace-any:safe

# 应用所有规则
npm run batch-replace-any

# 指定目录
npm run batch-replace-any -- --dir=src/services
```
