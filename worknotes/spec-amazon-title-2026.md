# Spec：Amazon 2026 商品名称（Title）适配与落地方案

- 状态：Implemented（定向验证通过；全量测试保留既有失败）
- 创建日期：2026-08-21
- 依据：`docs/【新规】商品名称要求和指南.pdf`（6 页；PDF 未提供政策生效日期）
- 范围：`sops` 亚马逊运营管理平台的 Listing 生成提示词、标题合规服务、Listing 文案辅助检查和运营知识页

## 0. 决策摘要

本次实现采用“上下文判定 + 标题/亮点分离 + 纯函数报告”的方案：

1. 保留 v1 作为旧数据和豁免场景的兼容规则集；v2 只在新规适用上下文运行。
2. 新规适用于除沙特阿拉伯（SA）、埃及（EG）、土耳其（TR）、阿联酋（AE）以外的商城，媒介类商品除外，并以首次发布商品为目标场景。
3. 适用场景下标题上限为 75 个字符（含空格）；商品亮点是独立字段，最多 125 个字符，使用逗号分隔短语。
4. 标题校验必须接收商城、类目、发布状态等上下文；自由粘贴区和 Deep Chat 只能做辅助提示，不能把未识别标题标成通过。
5. 规则报告中的 error 表示确定性不合规；warning/info 只表示最佳实践或需要人工复核，不把类目建议误写成全类目硬性型号规则。

## 1. PDF 规则基线

### 1.1 强制商品名称要求

- 标题应以尽可能少的信息清晰、准确描述商品。
- 标题不超过 75 个字符，空格计入字符数。
- 不得包含促销语或受限短语，例如 `kostenloser Versand`、`100%ige Qualitätsgarantie`、`FSA or HSA eligible` /“符合 FSA 或 HSA 要求”。
- 不得使用固定特殊字符：`! $ ? _ { } ^ ¬ ¦`。`~ # < > *` 仅可出现在商品编码或测量值等特定上下文，不能作为装饰。
- 同一实词最多出现 2 次；介词、冠词、连词可以超过 2 次。品牌名仍参与限制；品牌词在不同语境下的自然组成不自动视为重复。

### 1.2 适用范围与字段边界

- 新规范围：SA/EG/TR/AE 以外的商城；媒介类商品例外；明确面向首次发布商品。
- 已发布的违规标题仍可能被自动更正或不显示在搜索结果中；提交标题或亮点后展示可能需要 24–48 小时。
- 商品亮点不是标题扩容：最多 125 个字符，使用逗号分隔短语，不写完整句；显示在搜索结果和商品详情标题下方。
- 品牌名含标题禁用字符时，应放入“品牌名称”字段；品牌字段的特殊字符例外不适用于标题。无品牌商品在品牌字段填写“无品牌”。

## 2. 最佳实践（warning/info，不作为无条件硬拦截）

- 信息顺序建议为：品牌 → 风味/款式 → 商品类型 → 关键属性 → 颜色 → 尺寸/包装数量 → 型号。
- 型号只在特定类目风格指南要求时处理，不能作为全类目必填。
- 父 ASIN 标题不放颜色/尺寸；子 ASIN 标题应包含对应变体属性。变体很多时只保留最重要属性，其余放商品亮点。
- 使用阿拉伯数字而非英文拼写；`cm/oz/in/kg` 等计量单位缩写可以使用。
- 避免全大写和主观评价词（如 `Hot Item`、`Best seller`）。必要的 `- / , & .` 不应被固定字符集合误杀；是否使用分隔线仍需按语义和简洁性复核。

## 3. 现状与目标

| 现状 | 目标 |
|---|---|
| `titleComplianceService` 默认非 v2 回退 v1；豁免站点仍可能套 75 字符 | 解析请求上下文；豁免站点/媒介类回退 v1 基线，不强制 PDF 未规定的 50 字符 |
| 校验器无生产调用 | 提供可序列化报告；真实发布字段由调用方决定 warning 或最终阻止；粘贴区只做辅助提示 |
| FSA/HSA 未进入独立受限短语规则 | 新增大小写不敏感、组合形式和中文变体检测 |
| v2 提示词禁止计量单位缩写 | 改为允许 `cm/oz/in/kg` 等事实性缩写 |
| `BULLET_HIGHLIGHTS_MAX` 只用于超长提示 | 增加 highlights 输入和 125 字符校验，明确字段交接 |
| Deep Chat/Keyword Hunter 对整段文案计数或猜测标题 | 复用统一 Title/Titel 提取器；提取失败返回 `not_found`，不传空标题冒充通过 |
| 知识页存在 60/200、欧洲站通用、前 70–80/80、2026-07-27 过渡期等旧口径 | 统一为 PDF 可核验的范围、75/125 双字段和 24–48 小时展示时效 |

## 4. 接口与规则设计

`TitleComplianceInput` 增加以下可选上下文：

```ts
isFirstPublication?: boolean;
asinRole?: 'parent' | 'child';
variationAttributes?: { color?: string; size?: string };
highlights?: string;
```

版本处理：

- 显式 `version: 'v1'` 始终使用兼容规则；显式 `version: 'v2'` 在适用上下文启用新规。
- 省略版本时，保持既有 v1 行为；首次发布调用方应显式请求 v2，避免旧调用无意改变口径。
- v2 请求遇到 SA/EG/TR/AE 或媒介类时实际执行 v1 基线，报告回显 `appliedVersion: 'v1'`。
- `isFirstPublication` 传 `false` 时不启用 v2；历史数据可继续使用 v1。

确定性规则（error）：

- 适用场景的标题长度；
- 固定禁用字符及无上下文的条件字符；
- 促销语和 FSA/HSA 受限短语；
- 非豁免词的重复次数；
- 商品亮点超过 125 个字符。

启发式规则（warning/info）：

- 信息顺序、大小写、父子 ASIN 颜色/尺寸提示；
- 商品亮点是否近似逗号短语；
- 末尾标点和装饰性分隔符。

## 5. 执行路线

### P0：规则正确性

1. 先写标题服务回归测试，再实现适用性解析、FSA/HSA、亮点、单位缩写和 Unicode 字符计数。
2. 修正 v2 PromptLab 指令；测试必须验证“允许单位缩写”和“禁止完整 FSA/HSA 受限短语”。
3. 统一固定禁用字符与条件字符的边界测试。

### P1：辅助接线

1. 增加共享 Title/Titel 提取器，供 Deep Chat 和 Keyword Hunter 复用。
2. Keyword Hunter 对识别出的标题显示 Unicode 安全计数和报告摘要；未识别时显示明确状态。
3. 保留真实发布字段最终接线为调用方责任；自动校验不能从缺少 title/category 的人工 artifact 中臆造通过结果。

### P2：运营文档

1. 更新 SEO Strategy、Quality Listing、Listing SEO 页面中的旧口径和过长示例。
2. 保留现有已正确的 75 字符和商品亮点条目，仅补范围、FSA/HSA、品牌字段例外和展示时效。

## 6. 验收标准

- SA/EG/TR/AE、媒介类、非首次发布不会误套 v2 的 75 字符规则。
- 适用 v2 标题超过 75、包含促销/FSA/HSA 受限短语、固定禁符或实词超过 2 次时报告 error。
- `~ # < > *` 的编码/测量上下文通过，装饰性使用被报告；必要的 `&` 不被固定禁符误杀。
- `cm/oz/in/kg` 计量单位缩写在校验器和 v2 提示词中均被允许。
- highlights 超过 125 字符报 error，逗号短语格式仅作 warning。
- 父/子 ASIN 只有在调用方提供变体上下文时才触发属性提示。
- Title/Titel 无法识别时状态为 `not_found`，不会因空字符串返回“通过”。
- 相关单测、类型检查和目标文档搜索通过；未引入与本任务无关的改动。
