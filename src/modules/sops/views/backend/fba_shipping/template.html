标准发货流程

Step 1: 创建货件计划 (Shipping Plan)

进入 Seller Central → Inventory → Manage FBA Shipments → Send to Amazon

  • 选择正确的发货地址（Ship from address）
  • 选择包装类型：Individual / Case-packed
  • 确认每个 SKU 的发货数量
  • 选择物流方式：SPD（小包）/ LTL（卡车）

Step 2: 打印产品标签 (FNSKU)

产品标签打印规范：

  • 使用 热敏标签纸，确保清晰可扫描
  • 标签尺寸：1" x 2" 或 1" x 3"
  • 标签需覆盖原有条形码
  • 确保 FNSKU 与系统一致

Step 3: 打印箱标 (Carton Label)

箱标打印与张贴规范：

  • 使用 A4 纸打印，每箱 至少贴两张（相邻面）
  • 使用 热敏纸或覆膜 防止磨损
  • 箱标不可折叠、不可遮挡
  • 确保 Shipment ID 与货件一致

Step 4: 装箱与核对

装箱检查清单：

  • 数量核对：实际装箱数 = 系统申报数
  • 装箱单（Packing List）放入箱内
  • 产品有效封装，防止运输损坏
  • 填充物使用得当

Step 5: 确认并发货

最终确认并完成发货：

  • 在系统中点击 "Confirm Shipment"
  • 上传物流单号（Tracking Number）
  • 保存发货凭证和照片备查
