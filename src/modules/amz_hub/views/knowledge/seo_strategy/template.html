1. Amazon SEO 的官方定义

可见性 转化

核心口径： Amazon 官方把 SEO 定义为提升商品和品牌在 Amazon 搜索结果中可见性的策略集合。关键词不是孤立字段，标题、描述、图片、价格、销售表现、广告和账号健康都会影响搜索表现。

2. 关键词研究：短尾 + 长尾

官方数据 搜索意图

怎么取词： Amazon 官方建议结合搜索框建议、竞品详情页、Product Opportunity Explorer 和 Brand Analytics。短尾词负责覆盖核心类目，长尾词通常搜索量更低，但购买意图更明确、转化机会更高。

官方数据驱动的 SEO 闭环

先用 Product Opportunity Explorer / Brand Analytics 判断需求，再把关键词分配到标题、五点、描述和后台 Generic keyword，最后用 Search Query Performance、广告 Search Terms 和 Manage Your Experiments 验证曝光、点击、加购、购买与转化率。

1. 找词：先验证需求，再进入文案

官方 SEO 指南建议从 Amazon 搜索框、竞品 Offer、Product Opportunity Explorer 和 Brand Analytics 获取关键词。先把词分成类目短尾词、规格属性词、场景长尾词和品牌防守词，不要直接把所有词塞进标题。

数据源 POE / SQP / Top Search Terms / 广告搜索词
动作 按搜索量、购买意图、竞争程度给词打优先级
输出 主词 3-5 个，长尾词 10-20 个，后台词一组

2. 埋词：标题、五点、描述各司其职

Amazon 官方建议标题突出商品类型、品牌、颜色、尺寸等关键信息；描述用于补充材质、数量、尺寸、保养和保修信息；五点则聚焦最重要的设计、功能和使用场景。关键词要自然融入，避免重复堆砌。

标题 品牌 + 商品类型 + 核心属性，优先可读性
五点 一词短标题 + 100 字符内解释，突出场景价值
描述 承接长尾词，补齐客户做决定所需信息

3. 后台词：只放前台放不下但相关的词

Amazon SEO 指南说明后台 Generic keyword 可放同义词、缩写和替代叫法；避免重复、无关或误导性词。官方还建议使用小写字母、用空格分隔，并跳过冠词和介词，把空间留给真正能补充索引的词。

适合放 同义词、缩写、别名、当地拼写差异
不要放 竞品品牌、重复词、夸大词、无关词
维护节奏 每月按 SQP 与广告搜索词补缺，不频繁大换

4. 测试：用实验而不是感觉决定改版

Manage Your Experiments 可测试标题、图片、五点、描述和 A+ Content，并用销量、转化率、每独立访客销量、样本量等指标判断版本优劣。高流量 ASIN 应优先测试标题长度、主图角度和五点表达方式。

测试项 Title / Image / Bullet / Description / A+
看指标 Units sold / CVR / sales / sample size
周期 用官方默认设置跑到显著结果，不看短期波动

复盘口径：从搜索漏斗看 SEO 是否有效

不只看自然排名。用 Brand Analytics 和 Ads 报告把“展示机会、点击吸引、加购说服、购买转化”拆开判断。

曝光 SQP impression share / Search query volume
点击 Click share / CTR / clicked median price
加购 Cart add count / cart add share
购买 Purchase count / CVR / Search traffic sales
