使用指南 - AI驱动的高效工作流程

标准化作业程序 (SOP)

集成 AI大模型 辅助的高效工作流程，旨在引导标准化作业和最大化单人产出效率。

Step 1: 原始数据获取 (Day 1)

工具：前台插件 / 数据采集 / 卖家精灵 (JSON/CSV)

收集 Top 20-50 的竞品 Listing 内容和最近 3 个月的 Review。不要贪多，要精。
目标： 获取竞品Listing和Review。

Step 2: LLM 结构化清洗提取 (Day 1)

工具：Gemini 1.5 Pro / GPT-4

上传 JSON/CSV，选择合适的分析模板策略，生成 JSON 格式的使用场景、负面痛点、积极用户原话。
目标： 将非结构化文本转化为 COSMO 可理解的"意图节点"。

Step 3: 交叉验证与策略制定 (Day 2)

工具：ABA (Amazon Brand Analytics) + Excel

拿着 LLM 提取的"原生词"去 ABA 验证流量。确定主推词（高流量+高相关）和长尾词（高转化+特定场景）。
目标： 确认哪些"意图"是有市场需求的。

Step 4: 智能生成 Listing (Day 2)

核心动作：融合 Prompting

基于 A10/COSMO/Rufus 的逻辑，让 LLM 撰写 Listing。
  • Title: 包含 ABA 核心词 + 核心场景
  • Bullets: 前 3 点针对 COSMO 场景化，后 2 点针对 Rufus 解决痛点/参数
  • Description/A+: 讲述品牌故事，增加停留时间（A10 因素）

Step 5: 站外内容分发 (Ongoing)

目标：A10 权重激活

利用 AI 根据 Listing 内容生成 Blog Post, Social Media Captions。发布到相关垂直论坛或社媒，带上归因链接。
关键： 站外流量引入能极大提升 Listing 的自然排名权重。
