标题 (Title) 编写公式

[品牌] + [核心词] + [场景/人群] + [卖点] + [规格]

✅ 正确示例

BrandX Wireless Bluetooth Headphones for Running, Active Noise Cancelling, 40H Battery, Black

❌ 错误示例

Best Headphones 2024 NEW!!! Amazing Quality Cheap Price Free Shipping

字符限制： 200字符内，移动端显示前70字符

五点描述 (Bullet Points) 埋词逻辑

1
核心功能 + 主关键词 → COSMO意图匹配
2
使用场景描述 → 场景化搜索词
3
品质材质 + 长尾词 → 精准流量
4
解决痛点 → Rufus AI问答
5
规格参数 + 售后 → Rufus参数类问题

Search Terms 填充规范

✅ 正确做法

  • • 空格分隔关键词
  • • 不重复Title中的词
  • • 包含拼写变体/同义词
  • • 小写即可
  • • 用满250字节

❌ 禁止事项

  • • 逗号或标点分隔
  • • 竞品品牌名
  • • 主观词(best,amazing)
  • • 重复堆砌
  • • ASIN或价格

A+ 内容排版规范

模块1： 品牌Banner + Logo + Slogan
模块2-3： 产品核心卖点 (图文并茂)
模块4： 使用场景展示 / 对比表格
模块5： 产品规格参数一览
图片规范：970×600px / 300dpi / 白底 / 文字占比≤20%

移动端显示确认 (必做)

  • • 标题前70字符表达核心信息
  • • 主图移动端1:1显示是否聚焦
  • • Bullet前3条是否包含卖点
  • • 70%流量来自移动端！

A10/COSMO/Rufus 算法要点

A10：站外流量 + 停留时间 + 转化率
COSMO：场景意图匹配 (前3个Bullet)
Rufus：问答式理解 (后2个Bullet + 参数)
