# v3.0.7-rc.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布 `v3.0.7-rc.1` GitHub Pre-release，并用同一构建覆盖 Cloudflare Pages 生产环境。

**Architecture:** 通过一个只含版本和发布文档的 release commit 固定候选版本，再由 annotated tag 触发既有 GitHub Release workflow 生成可校验资产。Cloudflare Pages 直接上传本地已验证的 `dist` 到 `main` 生产分支；GitHub Latest 保持 `v3.0.6`。

**Tech Stack:** npm、Vite、Vitest、Playwright、GitHub Actions/CLI、Cloudflare Wrangler Pages

---
