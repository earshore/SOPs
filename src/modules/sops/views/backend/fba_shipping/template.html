标准发货流程

Step 1: 创建货件计划

Seller Central → Inventory → Send to Amazon

  • • 选择发货地址（海外仓/头程货代地址）
  • • 包装类型：Case-packed（同SKU装箱）/ Individual（混装）
  • • 填写每箱数量、尺寸、重量
  • • 选择物流：SPD（小包）/ LTL（卡车托盘）

Step 2: 打印产品标签 (FNSKU)

  • • 标签尺寸：1" x 2-5/8"（推荐）或 1" x 3"
  • • 使用热敏标签纸，确保条码黑白对比度
  • • 必须完全覆盖原厂条码（UPC/EAN）
  • • 危险品/易碎品需额外贴警示标签

Step 3: 打印箱标 (Carton Label)

  • • A4纸打印，每箱至少贴2张（相邻面）
  • • 覆膜处理防止运输磨损
  • • 确保 Shipment ID 与系统一致
  • • 禁止折叠、遮挡、贴在胶带上

Step 4: 装箱与核对

  • • 实际装箱数 = 系统申报数（误差为0）
  • • 装箱单（Packing List）放入箱内
  • • 气泡膜/填充物保护商品
  • • 封箱使用H型胶带法

Step 5: 确认并发货

  • • 系统点击 "Confirm Shipment"
  • • 上传物流单号（PRO Number / Tracking）
  • • 保存发货凭证、装箱照片备查
  • • 货件状态变为 "Shipped" 后监控入库

常见入库问题与处理

数量不符： 立即开Case申诉，提供装箱照片、物流POD
标签无法扫描： 产生$0.20/件罚款，需改进打印设置
超重罚款： $25-$50/箱，严重影响利润
货件分拆： 正常现象，分别发往不同FC
