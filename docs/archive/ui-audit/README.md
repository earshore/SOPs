Current visual and theme guidance lives in:

- `../../VISUAL_DESIGN_GUIDELINES.md`
- `../../THEME_SYSTEM_GUIDELINES.md`
- `../../PAGE_ENTRY_ANIMATION_GUIDELINES.md`
- `../../CARD_UI_DEBT_REDUCTION_PLAN.md`

## Files

- `UI_UX_REMEDIATION_BACKLOG.md` - Historical remediation backlog derived from the audit.
- `BANNER_FIX_SUMMARY.md` - Completed high-priority welcome banner fixes.
- `BANNER_MEDIUM_PRIORITY_FIX.md` - Completed medium-priority welcome banner fixes.
