## 🛠️ 创建的工具

### 1. 迁移工具

**文件**: `scripts/migrate-hardcoded-values.ts`

**功能**:
- 自动检测硬编码颜色、时长、缓动、圆角
- 批量替换为设计令牌
- 支持预览模式和执行模式
- 详细的修改报告

**使用**:
```bash
# 预览模式
npm run css:migrate-hardcoded:dry

# 执行模式
npm run css:migrate-hardcoded
```

### 2. 语法修复工具

**文件**: `scripts/fix-css-syntax-errors.ts`

**功能**:
- 修复错误的var()嵌套
- 修复遗漏的cubic-bezier值
- 修复额外的rgba颜色值
- 批量处理所有模块CSS

### 3. 审查工具

**文件**: `scripts/audit-css-variables.ts`

**功能**:
- 检测设计令牌使用率
- 识别硬编码值
- 生成审查报告

**使用**:
```bash
npm run css:audit
```
