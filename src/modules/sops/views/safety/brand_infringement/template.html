红线规定 - 侵权零容忍

任何Listing文案修改必须经过侵权词库过滤。未经审核擅自上架导致侵权投诉的，追究当事人责任。侵权导致的账号风险将严重影响全店业务。

商标侵权
→ Listing下架 + 警告
专利侵权
→ 法律诉讼 + 赔偿
多次侵权
→ 账号停用

上架前审核流程

Step 1: 关键词商标查重

工具：USPTO / EUIPO / WIPO

  • • 标题所有关键词逐一查询商标数据库
  • • USPTO - 美国商标
  • • EUIPO - 欧盟商标
  • • 第三方工具：Trademarkia、知元查

Step 2: 侵权词库过滤

公司内部维护的禁用词表

  • • 品牌侵权词（Apple, Nike, Disney...）
  • • 专利敏感词（Patented, ™, ®）
  • • 明星/IP名称（Marvel, Pokemon...）
  • • 虚假认证词（FDA Approved, CE Certified）

Step 3: 图片版权确认

确保所有图片来源合法

  • • ✅ 自有摄影/设计（首选）
  • • ✅ 购买正版授权（保留凭证）
  • • ✅ 工厂提供（需书面授权）
  • • ❌ 禁止网络下载使用

Step 4: 审核签字确认

留档备查

  • • 填写《Listing上架审核表》
  • • 审核人签名 + 日期
  • • 审核结论：通过/驳回
  • • 归档保存（至少2年）

常见侵权类型速查

商标侵权 (Trademark)

使用他人注册商标或近似词汇

例："compatible with iPhone" → 改为 "compatible with i-Phone 14/15"

专利侵权 (Patent)

产品外观或功能涉及他人专利

新品开发前先做专利检索，使用 Google Patents 或专利局网站

版权侵权 (Copyright)

使用网络图片、卡通形象、艺术作品

使用 TinEye 反向搜索检查图片是否有版权

虚假宣传 (False Claims)

虚假认证声明、夸大功效

禁用：FDA Certified, CE Approved, Doctor Recommended

"Compatible With" 安全表述

"Replacement for [Brand]" → 安全
"Fits [Model Number]" → 安全
"For iPhone" (独立使用) → 风险
"[Brand] Style" → 禁止
