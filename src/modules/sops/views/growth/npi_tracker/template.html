新品生命周期阶段

测款期 (0-30天)

上架后观察期。完成合规检查，启动Vine，测试广告响应。关键指标：CTR>0.5%，CVR有数据。

成长期 (30-90天)

积累评价、优化广告。目标：评分≥4.0，ACOS<40%，自然单占比提升。

稳定期 (90天+)

稳定出单，控制广告预算。目标：自然单占比>50%，利润率达标。

清仓期

库存周转>60天或持续亏损触发。降价至动销价或清仓红线止损。

上架前合规检查 (5项必做)

泛欧计划：确认是否启用Pan-EU，影响定价策略
Rufus优化：五点+标题包含场景词、解决痛点
敏感词：禁用侵权词、医疗声明、夸大宣传
图片+QA：主图白底、6张副图、常见QA预埋
A+页面：品牌故事+对比模块+场景展示

提示：合规状态显示✓表示全部通过，否则显示完成数/总数

"保留/放弃"决策标准

✓ 继续保留条件
  • • ACOS < 目标值 (通常40%)
  • • 评分 ≥ 4.0
  • • 自然单占比上升趋势
  • • 库存周转 < 60天
✗ 建议放弃条件
  • • 连续30天ACOS>60%且无改善
  • • 评分 < 3.5 且差评无法解决
  • • 库存周转 > 90天
  • • 售价已低于清仓红线仍无销量

定价计算公式 (基于配送费自动计算，确保不亏损)

新品定价

= 市场均价 × 0.9

低于市场价10%切入

清仓红线

= 配送费 ÷ 0.5

配送占比50%，到此即亏损

动销价格

= 清仓红线 + €1

微利促销价，保本为主

建议售价

= 清仓红线 + €2

目标日常售价，利润合理
