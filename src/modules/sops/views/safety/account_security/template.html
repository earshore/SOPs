账号登录与环境安全 SOP

已发布

规定登录设备、IP隔离原则，禁止在公司网络登录任何私人亚马逊相关的买家/卖家账号。

安全风控体系 优先级：最高

红线警告

一经发现违反本SOP规定，直接清退，并追究责任。账号安全是公司生命线，任何疏忽都可能导致账号关联或封禁。

核心规范

1. 登录设备规范

  • 必须使用 紫鸟超级浏览器 或公司指定的 VPS 登录卖家后台
  • 每个店铺对应固定的浏览器环境/VPS，严禁混用
  • 紫鸟浏览器环境需定期检查指纹配置，确保唯一性

2. IP 隔离原则

  • 每个店铺必须使用 独立固定IP（静态住宅IP或干净的机房IP）
  • 严禁使用公司办公网络直连登录任何亚马逊卖家后台
  • IP一旦分配，不得随意更换，换IP需向主管报备

3. 绝对禁止行为

  • 禁止 在公司网络登录任何私人亚马逊账号（包括买家账号）
  • 禁止 使用个人手机/平板登录公司店铺后台
  • 禁止 在店铺环境浏览器内访问其他电商平台
  • 禁止 将登录凭证（密码、OTP设备）透露给任何人
