# 2026-06-05

- 排查 Cloudflare Pages 部署后 CSP 报错：定位到 `public/_headers` 的 `script-src` 禁止 `unsafe-eval`，而项目 `src/main.ts` 使用普通 `alpinejs` 构建，Alpine 在解析动态插入的 `systemSettings.html` 等模板中的 `x-*` 表达式时调用 `new AsyncFunction`，被 CSP 拦截。结论：与 IndexedDB/localStorage 分层本身无直接关系；新增本地数据管理面板扩大了 Alpine 指令触发面。
- 按用户要求先临时恢复线上业务：已在 `public/_headers` 的 CSP `script-src` 中加入 `'unsafe-eval'`，并运行 `npm run build` 验证通过。后续应迁移到 Alpine CSP build 或移除复杂内联表达式后再收紧 CSP。
- 继续制定长期迁移方案：建议分阶段从普通 `alpinejs` 迁移到 `@alpinejs/csp`，重构复杂 Alpine 内联表达式到组件方法/getter，最后移除 `public/_headers` 中的临时 `'unsafe-eval'` 并增加自动扫描和 E2E 回归。
