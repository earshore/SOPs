Send to Amazon 工作流

Step 1: 选择库存

Inventory → FBA Inventory → Send to Amazon

  • • 选择要发货的SKU
  • • 确认发货地址(Ship from)

Step 2: 确认包装类型

  • • Individual products: 混装不同SKU
  • • Case-packed: 每箱单一SKU

Step 3: 标签贴附设置

  • • Seller: 自行贴FNSKU(免费)
  • • Amazon: 亚马逊贴标($0.30/件)

Step 4: 填写装箱信息

  • • 箱数、每箱数量
  • • 箱子尺寸(长x宽x高)
  • • 实际重量(含包装)

Step 5: 选择承运方式

  • • SPD: 小包裹(≤6箱)
  • • LTL: 卡车/托盘运输
  • • 合作承运商可享折扣

产品标签 (FNSKU)

标签规格要求

  • 推荐尺寸：1" x 2-5/8" (2.5 x 6.6cm)
  • 备选尺寸：1" x 3" (2.5 x 7.6cm)
  • 打印方式：热敏标签/激光打印
  • 条码类型：Code 128

完全覆盖原厂条码

黑白高对比度

禁止折叠/遮挡

禁止贴在胶带上

箱子标签 (Carton Label)

A4纸打印，不缩放
每箱贴2张在相邻面
透明胶带覆膜保护
禁止：折叠、遮挡、贴在封箱胶带上

装箱与预处理要求

标准装箱要求

  • ✓ 使用6面完好的标准纸箱
  • ✓ 使用足够的填充物(气泡膜/填充纸)
  • ✓ H型封箱法(顶底+四周)
  • ✓ 装箱单(Packing List)放入箱内

特殊品类预处理

  • 液体：密封+气泡袋
  • 易碎：六面防护+易碎标签
  • 尖锐：裹边保护
  • 多件套：统一外包装+Set标签

常见入库问题与费用

超重(单箱>50lbs) $25-$50/箱
标签无法扫描 $0.20/件
缺少预处理(套袋等) $0.30-$1.50/件
箱内数量不符 需开Case申诉
