核心投放理念：先放量跑词→再筛选收割→最终盈利

新品期不要怕ACOS高，关键是跑出转化词；成长期要敢于加大预算抢占自然坑位；成熟期靠自然单盈利、广告仅做防守。

新品冲刺期 (0-2周)

≤ 80%

烧钱跑词，不计成本抢曝光

新品推广期 (2周-3月)

≤ 50%

优化词组，培养自然排名

成长期 (3-6月)

≤ 30%

自然单占比目标40%+

成熟/维护期 (6月+)

≤ 15%

广告仅防守，主靠自然单

新品广告架构 (Day1-7)

1. 自动广告 (必开)

  • • 紧密匹配：$0.8-1.2（核心流量）
  • • 宽泛匹配：$0.5-0.8（扩词）
  • • 同类商品：$0.6-1.0（抢竞品）
  • • 关联商品：$0.3-0.5（测试）

💡 前7天跑数据，收集转化词

2. 手动广泛 (Day7后)

  • • 从自动广告提取出单词
  • • 出价：自动广告CPC×1.2
  • • 目的：放大有效词流量

3. 手动精准 (Day14后)

  • • 选ACOS<30%的核心大词
  • • 出价：广泛CPC×1.3
  • • 单独开活动抢首页坑位

4. ASIN定投 (可选)

  • • 定投竞品ASIN (评分<4.2的)< /li>
  • • 定投自己互补产品(关联)

关键词漏斗挖掘

自动广告 → 搜索词报告

跑7天以上，收集曝光>100的词

筛选：点击>5 & 有订单

提取到手动广泛，继续验证

筛选：ACOS<目标 & 订单>3

晋升到手动精准，重点投放

核心词上首页 → 自然流量

广告降预算，自然单成为主力

出价策略参考

新品冲刺 建议出价×1.5~2.0
稳定投放 建议出价×1.0~1.2
收割盈利 建议出价×0.7~0.9
首页Top位 +50%~100%溢价

首页Top位转化率通常是其他位置的2-3倍，值得加价抢占

每周必做优化动作

否词 ：花费>$15无单、ACOS>100%超7天
加词 ：自动出单词→广泛、广泛出单词→精准
调价 ：ACOS<目标×0.7加价15%，>目标×1.5降价15%
预算 ：每天12点前花完→加20%预算
分时 ：高峰时段(当地10-14点)可加价30%

常见问题诊断

❌ 曝光很高但没点击

→ 主图不够吸引、标题没有卖点、价格没有竞争力

❌ 点击很多但不转化

→ 关键词不精准、Listing信息不足、无评价或差评

❌ ACOS一直降不下来

→ 产品本身问题(评分/价格/图片)，需先优化Listing

❌ 自然单占比上不去

→ 核心词未上首页，继续投精准抢坑位

进阶打法：大卖常用策略

🎯 抢首页策略

  • • 单独开一个精准广告组
  • • 只放1个核心大词
  • • 出价：建议价×2+首页溢价50%
  • • 目标：把自然位推到首页

🔄 低价螺旋法

  • • 新品期设低于市场均价10-15%
  • • 配合广告冲排名
  • • 自然位稳定后逐步提价
  • • 每周提3-5%，直到目标价

📊 预算分配法

  • • 精准词组：60%预算
  • • 广泛/自动：30%预算(拓词)
  • • ASIN定投：10%预算(抢竞品)
  • • 每周复盘调整比例
