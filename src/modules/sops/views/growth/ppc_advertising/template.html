PPC 核心思维框架

1. 广告是推自然排名的工具，不是盈利的手段。真正的利润来自自然单。广告的终极目标是推动自然排名上去后逐步降低广告依赖。
2. TACoS 才是北极星指标，不是 ACOS。ACOS 只看广告效率，TACoS（广告花费/总销售额）才能反映广告对整体业务的真实贡献。
3. Listing 转化率决定广告效率上限。CTR 靠主图和价格，CVR 靠 Listing 质量。广告花再多钱，Listing 烂照样亏。
运营真相：你不需要成为PPC专家。掌握本SOP中 80/20 原则——20%的操作产生80%的效果。每周花2小时就够了。

PPC 铁律

不要频繁调整！每次调整后至少等 7 天再看数据。亚马逊广告数据有 48-72h 延迟，频繁操作等于盲调。
不要只看 ACOS！新品期 ACOS 80% 很正常。关键看 TACoS 趋势 + 自然排名是否在上升。
不要 Listing 没准备好就开广告！没主图、没评价、没价格优势=烧钱打水漂。
不要中途断货！推广期断货=前功尽弃。广告推起来的自然排名在断货后 3-5 天就会暴跌。
不要一个广告组塞太多词！每组最多 5-8 个关键词，否则预算被分散，数据无法聚焦。

Phase 0：开广告前的 Listing 体检 — 不过关不开广告

真相：90% 的广告效果差，问题不在广告本身，而在 Listing。 广告只是把流量带到你面前——转不转化取决于价格、主图、评价、Listing 内容。 先修内功再开广告，否则就是烧钱。
必

价格竞争力

新品定价低于竞品均价 €0.5-2 或 设置 10-15% Coupon（绿标签加持点击率）。没有价格优势的新品推起来成本翻倍。

必

主图差异化

在搜索结果页中，你的主图必须在 0.5 秒内与竞品区分开。白底图已不够——角度/构图/颜色要有辨识度。A/B Test 如果可以更好。

必

评价基础

至少 1 条带图/视频的 4+ 星 Review。0 评价开广告 = 送钱给竞品。Vine 计划必开（€200/ASIN，值得）。理想状态：5+ 条评价再正式大规模投放。

高

标题 + Bullet Points

标题前 80 字符包含 2-3 个核心关键词 + 主卖点。Bullets 覆盖买家最关心的 5 个问题（参考 QA SOP 中的高频问题）。

高

A+ 页面 + 视频

A+ 页面完成 → 提升 CVR 3-10%。产品视频已上传 → 占据搜索结果视频坑位 + 提升页面停留时间。

建

库存 + FBA 到货

确保 FBA 库存至少覆盖 60 天销售。推广期断货 = 前功尽弃，广告推起来的排名 3-5 天就会暴跌。

广告架构全景图 — 四种广告类型 × 职能分工

运营不需要同时开所有类型。按优先级逐步叠加：SP 是基础，SB/SBV 是加分项，SD 是进阶。

SP

Sponsored Products

核心 · 必开
职能：搜索结果页精准拦截 + 推动自然排名
包含：
  • • 自动广告（紧密/宽泛/同类/关联）
  • • 手动广泛 → 手动词组 → 手动精准
  • • ASIN 定投（Product Targeting）
预算占比：广告总预算的 65-75%
适用阶段：所有阶段（从 Day 1 到永远）
SB

Sponsored Brands / Video

品牌 · 建议开
职能：搜索结果页头部/底部品牌曝光 + 视频坑位占据
包含：
  • • SB 品牌头条（需品牌注册）
  • • SBV 视频广告（CPC 通常更低！）
  • • 链接到 Brand Store 或产品页
预算占比：广告总预算的 15-25%
适用阶段：有品牌注册 + 有视频素材后开启
SBV 是被低估的武器：视频广告 CTR 通常比纯图片高 2-3 倍，CPC 反而更低。15 秒竖版产品视频就够用。
SD

Sponsored Display

进阶 · 可选
职能：竞品页面拦截 + 站外再营销 + 品牌防守
核心用法：
  • • 竞品 ASIN 定投（出现在竞品详情页）
  • • 浏览再营销（看过你/竞品但没买的人）
  • • 品类定投（按品类/价格/评分筛选）
预算占比：广告总预算的 5-15%

格式：[站点]-[广告类型]-[匹配方式]-[ASIN/产品简称]-[用途]

新品投放四阶段作战计划

Phase 1

冲刺收录期 — Week 1-2

目标：让系统认识你

开启的广告（5 个活动）

① SP 自动-紧密匹配（最重要）
竞价：建议价 × 1.0 ｜ 日预算：€10-15
→ 让亚马逊识别你的产品属于哪个品类/关键词
② SP 自动-宽泛匹配
竞价：建议价 × 0.8 ｜ 日预算：€5-8
→ 发现你没想到的长尾词机会
③ SP 自动-同类商品
竞价：建议价 × 0.7 ｜ 日预算：€5-8
→ 出现在同类产品详情页
④ SP 手动-广泛（5-8 个核心词）
竞价：建议价 × 1.0-1.2 ｜ 日预算：€10-15
→ 主动出击核心关键词
⑤ SP ASIN定投（3-5 个竞品 ASIN）
竞价：建议价 × 0.8 ｜ 日预算：€5-8
→ 出现在竞品页面下方"比较"区域

关键词选词来源

  • • ABA (Brand Analytics)：搜索词排名 TOP 词
  • • 卖家精灵/Helium10：反查 TOP 3 竞品的流量词
  • • 亚马逊搜索框：输入核心词看自动补全建议
  • • 竞品标题：前 80 字符中的关键词
  • • ⚠ 欧洲站必须用当地语言关键词！不要用英语词打 DE/FR/IT/ES 站。

Phase 1 期间的心态

  • • ACOS 80-120% 是正常的，不要慌
  • • 这个阶段只看 曝光量 和 点击率(CTR)
  • • CTR < 0.3% → 主图/标题有问题，先去优化 Listing
  • • 每天花 5 分钟检查预算是否耗尽（被花完=该加预算）
  • • 不要否词！这个阶段数据量不够，否词可能误杀
💰 Phase 1 日预算参考：

总日预算 €35-55/ASIN。低客单价产品(€10-20)取下限，高客单价(€30+)取上限。不要怕花钱，这是投资期。

Phase 2

数据筛选期 — Week 3-4

目标：找出出单词，干掉废词

核心动作：关键词漏斗

1. 下载搜索词报告
后台 → Advertising → Reports → Search Term Report（选最近 14 天）
2. 找出"出单词"
筛选条件：Orders ≥ 2 且 ACOS ≤ 目标 ACOS × 1.5
→ 这些词转入 手动精准广告组，加预算死磕
3. 否掉"废词"
筛选条件：Clicks ≥ 15 且 Orders = 0
→ 在自动/广泛组中添加为 否定精准
4. 观察"潜力词"
筛选条件：Orders = 1 且 Click ≤ 20
→ 继续观察一周，如果再出单 → 升级为精准

新增广告活动

⑥ SP 手动-精准（出单词）
竞价：建议价 × 1.2-1.5 ｜ 日预算：€15-20
→ 核心出单词集中火力，推自然排名
⑦ SBV 视频广告（如果有视频素材）
竞价：建议价 × 0.8 ｜ 日预算：€5-10
→ 低成本抢占视频坑位

⚡ 关键词漏斗逻辑

自动广告 → 发现新词
↓ 出单 2+ 次
手动广泛 → 扩大匹配
↓ 稳定出单
手动词组 → 缩小范围
↓ 确认高转化
手动精准 → 集中火力

同时：出单词从自动/广泛组中否定精准，避免预算内耗

Phase 3

排名冲刺期 — Month 2-3

目标：核心词自然位上首页

抢首页策略

  • • 挑选 2-3 个核心大词（月搜索量最高 + 与产品最相关）
  • • 为每个词单独开一个精准广告活动
  • • 出价：建议价 × 1.5-2.0
  • • Placement 调整：Top of Search 溢价 50-100%
  • • 配合 Coupon + 适当降价提高 CVR
  • • 每天用卖家精灵检查自然排名变化
  • • 目标：把核心词自然位推到首页（位置 1-20）

Placement 策略详解

  • • Top of Search (TOS)：搜索结果第一行。CVR 最高但 CPC 最贵。核心出单词重点投这里。
  • • Rest of Search (ROS)：搜索结果第 2 页+。CPC 低，适合长尾词和拓词。
  • • Product Pages (PP)：竞品详情页。适合 ASIN 定投和防守。

判断自然位是否上来了

  • • 卖家精灵 → 关键词排名追踪 → 监控自然位变化
  • • 后台 Brand Analytics → Search Query Performance
  • • 自然位进入前 20 → 可以开始降低该词的广告出价
  • • 自然位进入前 10 → 广告转为防守模式
Phase 4

利润收割期 — Month 4+

目标：广告转防守，利润最大化

降本增效动作

  • • 自然位已稳定首页的词 → 广告出价降 20-30%
  • • ACOS 持续高于盈亏线的词 → 降价或暂停
  • • 自动/广泛广告 → 降到最低预算（€3-5/天），仅做持续拓词
  • • 精准广告 → 保留出单词，降价至刚好维持曝光
  • • 逐步恢复产品价格到目标利润水平

成熟期广告的作用

  • • 防守：防止竞品抢你的关键词首页位
  • • 拦截：SD 定投竞品 ASIN，吃竞品流量
  • • 品牌：SB 品牌头条，保护品牌词搜索
  • • 拓新：自动广告低预算持续发现新词
  • • 📊 健康状态：广告单占比 30-40%，自然单 60-70%

否词管理体系 — 省钱的核心技能

否词做得好=直接省 20-40% 的广告费。这是运营 PPC 优化中 ROI 最高的动作。

❌ 必须否掉的词

规则1： 点击 ≥15 次 且 订单 = 0 → 否定精准
规则2： 花费 > 产品售价 × 2 且 订单 = 0 → 否定精准
规则3： ACOS > 盈亏线 × 3 且 持续 14 天+ → 否定精准
规则4： 明显不相关的搜索词（另一个品类/产品）→ 否定词组

⚠️ 否词注意事项

  • • 否定精准 vs 否定词组：大部分情况用"否定精准"。否定词组会连带否掉包含该短语的所有搜索词——可能误杀。
  • • 数据量不够不要否：Phase 1 不否词。至少积累 7 天 + 15 次以上点击再判断。
  • • 出单词否自动不否精准：转入精准组的词，要在自动/广泛组中否掉，避免两个组抢同一个词。
  • • 建否词清单：Excel 记录所有否过的词，避免重复添加或误恢复。

📋 欧洲站通用预设否词库

以下词在大多数产品品类中都应提前否掉（新建广告活动时直接添加）：

英语/通用：

free, cheap, second hand, used, refurbished, wholesale, bulk, DIY, how to, what is, review, test, vergleich, alternative

德语：

gebraucht, kostenlos, billig, selber machen, anleitung, erfahrung, bewertung, defekt, kaputt, reparatur

法语：

gratuit, pas cher, occasion, d'occasion, comment, tutoriel, avis, comparatif

竞品品牌名：

在自动广告中否掉主要竞品品牌名，除非你有意做竞品拦截。品牌词搜索的转化率对你来说通常很低。

技巧：否词库按站点维护（DE/FR/IT/ES 各一份）。新品上线时批量导入，省得每次重新添加。

出价调整规则 — 量化决策，不凭感觉

所有出价调整基于至少 7 天 + 至少 20 次点击的数据。数据不够的先不动。

数据表现 ACOS vs 目标 动作 调整幅度 逻辑
高转化 + 低ACOS ACOS < 目标 × 0.7 ⬆ 加价 +10-20% 利润空间充足，加价抢更多曝光和单量
正常出单 目标×0.7 ≤ ACOS ≤ 目标×1.3 — 不动 0% 在合理范围内，保持稳定
ACOS偏高但有单 目标×1.3 < ACOS < 目标×2 ⬇ 降价 -10-15% 小幅降价，观察 7 天后再决定
ACOS远超目标 ACOS > 目标 × 2 ⬇ 大降/暂停 -20-30% 先降价，14天无改善→暂停该词
有曝光无点击 Impressions 高，CTR < 0.2% 检查 Listing — 不是出价问题，是主图/价格/标题问题
无曝光 Impressions < 100/周 ⬆ 大幅加价 +30-50% 出价太低拿不到展示，先加价获取数据
黄金原则：每次调整只改一个变量（出价或预算，不要同时改）。改完等 7 天看数据。频繁调整=盲调=浪费数据积累。

欧洲多站点广告策略

🇩🇪 德国站（核心战场）

  • • 流量：欧洲最大站，CPC 最高（€0.3-0.8 常见）
  • • 预算：占欧洲总预算 40-50%
  • • 关键词：必须用德语，英语词几乎无效
  • • 特点：转化率高但竞争激烈
  • • 注意：德语复合词很长（Küchenmesser-Set）需完整匹配
  • → 精细化运营，否词要狠

🇬🇧 英国站

  • • 流量：第二大站，CPC 中等（€0.2-0.5）
  • • 预算：占欧洲总预算 25-35%
  • • 关键词：英式英语拼写（colour, aluminium）
  • • 特点：脱欧后独立站，广告不与EU联动
  • • 货币：GBP，注意汇率对利润率的影响
  • → 独立运营，不要和 EU 混管

🇫🇷 法国站

  • • 流量：EU第二大，CPC 较低（€0.15-0.35）
  • • 预算：占欧洲总预算 10-15%
  • • 关键词：必须用法语，注意重音符号
  • • 特点：CVR 略低于 DE，但 CPC 便宜很多
  • • 机会：竞争度远低于 DE，ROI 往往更好
  • → 低成本高ROI的利润站

🇮🇹🇪🇸 意大利/西班牙站

  • • 流量：中等偏低，CPC 最低（€0.10-0.25）
  • • 预算：各占欧洲总预算 5-10%
  • • 关键词：必须用意/西班牙语
  • • 策略：可以用 Broad/Phrase 更宽松的匹配
  • • 机会：很多品类竞品极少，自动广告就能拿到好位置
  • → 低投入捡漏

🇳🇱🇸🇪🇵🇱 新兴站点

  • • 流量：低但成长中，CPC 极低（€0.05-0.15）
  • • 预算：合计 5%（象征性）
  • • 策略：只开自动广告-紧密匹配
  • • 语言：NL/SE 可用英语；PL 建议用波兰语
  • • 特点：红利期，低投入高回报
  • → 自动广告捡漏即可

小语种关键词注意

  • • 绝不能用翻译软件直译关键词！
  • • 正确做法：卖家精灵/H10 反查该站点竞品的实际流量词
  • • 德语复合词：Küchenmaschine（厨师机）不等于 Küche + Maschine
  • • 法语重音：crème ≠ creme，搜索结果不同
  • • 西班牙语：同一产品在西班牙和拉美叫法可能不同
  • → 错误关键词=把钱烧给不相关的流量

每周三优化工作流 — 固定 2 小时搞定

所有优化固定在周三上午。周一二数据还没完全更新，周三看到的是上周完整数据（含48h延迟）。

1

下载数据（5 分钟）

后台 → Advertising → Reports → 下载 Search Term Report（过去 7 天 + 过去 30 天）。 下载 Campaign Performance Report 对照。

2

否词操作（20 分钟）

按否词规则筛选废词 → 添加到对应广告组的否定列表。 这一步对节省预算影响最大。

3

升词操作（15 分钟）

找出自动/广泛中的出单词 → 转入精准组 → 同时在原组否定精准。 关键词漏斗：自动→广泛→词组→精准。

4

调价操作（15 分钟）

按出价调整规则表操作。高效词加价 10-20%，低效词降价 10-15%。 每次只调一个变量，等 7 天再动。

5

预算检查（10 分钟）

每天 12 点前花完 → 加 20% 预算。 整天花不完 → 不动（不要降预算，可能是周期性波动）。 检查是否有广告活动意外暂停。

6

指标记录（10 分钟）

记录本周 ACOS / TACoS / 自然单占比 / 核心词排名到 Google Sheet。 对比上周数据判断趋势。4 周趋势比单周数据更有意义。

运营真相：上述 6 步合计 75 分钟。加上看数据思考时间，总共约 2 小时。 固定在周三上午处理，其他日子不碰广告后台——频繁查看只会让你焦虑并做出错误决策。 除非预算异常（某天花了平时3倍以上），否则中间不要干预。

广告问题诊断决策树

😤 症状：有曝光没点击（CTR < 0.3%）

诊断方向：问题在 Listing 表现层面，不是广告问题

  • ① 主图是否与竞品有差异化？在搜索页截图对比
  • ② 价格是否有竞争力？是否显示 Coupon 绿标签？
  • ③ 标题前 80 字符是否包含核心卖点？
  • ④ 星级评分是否低于 4.0？
  • ⑤ 是否有 Prime 标志？FBM 的 CTR 远低于 FBA

→ 修 Listing，不是调广告

😤 症状：有点击不转化（CVR < 5%）

诊断方向：流量不精准 或 Listing 详情页没说服力

  • ① 检查搜索词报告：是否大量不相关词在消耗预算？→ 否词
  • ② 副图是否充分展示产品？是否有对比图/使用场景图？
  • ③ Bullet Points 是否回答了买家最关心的问题？
  • ④ 评价内容是否有明显劝退的差评？
  • ⑤ A+ 页面是否完善？

→ 否词 + 优化 Listing 详情页

😤 症状：ACOS 一直降不下来（>50%超过4周）

诊断方向：可能是结构性问题

  • ① 产品毛利率是否太低？（毛利<30%→广告空间极小）
  • ② 品类 CPC 是否天然高？（某些品类 CPC €1+ 是常态）
  • ③ 是否还在给废词花钱？→ 彻底清理一次否词
  • ④ 预算是否被无效广告组分散？→ 暂停低效活动
  • ⑤ 是否该用 Coupon/降价提高 CVR 来降 ACOS？

→ 从产品利润结构层面审视

😤 症状：自然单占比上不去（<30%超过3月）

诊断方向：自然排名没有被广告有效推动

  • ① 检查核心词自然排名——是否还在 2-3 页之外？
  • ② 广告订单是否集中在核心词上？（分散=无法推排名）
  • ③ 是否需要加大核心词的精准投放力度？
  • ④ Listing 是否被亚马逊收录了足够多的关键词？
  • ⑤ 竞品是否在加大投放导致你被挤出去？

→ 集中火力打 2-3 个核心词冲首页

广告预算规划 — 运营务实算法

新品推广预算计算公式

月度广告预算 = 预期月销售额 × 目标TACoS

示例：

预期月销售额：€3000（日均 €100）

新品期目标 TACoS：25%

月度广告预算 = €3000 × 25% = €750/月（≈ €25/天）

各站点分配（按上方占比）：

DE：€375 → IT/ES：各 €75 → FR：€112 → 其他：€38

预算红线

广告花费 > 毛利的 50% 且持续 4 周+ → 停下来审视产品本身是否值得继续推
新品推广期可以接受 2-3 个月亏损——但要有明确的 TACoS 下降趋势，否则产品可能不适合这个市场
健康信号：TACoS 每月下降 3-5 个百分点 + 自然单占比每月增加 5-10%
运营务实原则：不要同时推超过 3 个新品。预算和精力都跟不上，每个都推不好。

进阶策略 — 成熟后使用

以下策略适合产品进入成长/成熟期后使用。新品期不要同时尝试太多策略——先把基础的 SP 精准跑顺。

🎯 竞品 ASIN 定投

  • • 选择评分低于你 / 价格高于你 / 评价少于你的竞品
  • • 用 SP Product Targeting 或 SD ASIN 定投
  • • 你的广告出现在竞品详情页
  • • CPC 通常比关键词便宜 30-50%
  • • 注意：选好打的竞品，不要挑比你强的打

📊 分时段竞价（Dayparting）

  • • 欧洲购物高峰：当地时间 19:00-22:00
  • • 次高峰：12:00-14:00（午休浏览）
  • • 低谷：凌晨 2:00-7:00
  • • 策略：预算设为全天能花到 22:00 的量
  • • 亚马逊原生不支持分时，可用第三方工具
  • • 运营简化做法：确保预算不在下午就花完即可

🛡️ 品牌词防守

  • • 开一个 SB 广告打自己的品牌名
  • • CPC 极低（品牌词几乎没竞争）
  • • 防止竞品广告出现在你的品牌搜索结果中
  • • 品牌词 CVR 通常 >25%，ACOS 极低
  • • 成本几乎为零的防守动作

🏷️ 促销期广告配合

  • • Prime Day / Black Friday / 圣诞前：预算加 50-100%
  • • 活动前 1 周开始加预算（预热期）
  • • 活动当天出价加 30-50%
  • • 活动后 3 天恢复正常预算
  • • Coupon + Deal + 广告三管齐下效果最好
  • • 欧洲特有：各国有不同促销节点（DE: 复活节, FR: 法国日等）

📈 低价螺旋法

  • • 新品定价：竞品均价 × 0.85-0.90
  • • 低价 + 广告 → 高 CVR → 快速推排名
  • • 自然位稳定首页后 → 每周提价 3-5%
  • • 同时逐步降低广告出价
  • • 直到价格恢复目标利润水平
  • • 核心：用短期利润换长期排名

🔄 交叉 ASIN 流量互导

  • • 如果你有多个相关产品（如同系列不同颜色/规格）
  • • 用 SD 定投自己的其他 ASIN → "经常一起买"
  • • SB 展示多个产品 → 品牌集群效应
  • • 老品带新品：老品页面广告位给新品曝光
  • • 成本极低且不会损害任何产品

📈 健康趋势判断

✅ 健康信号（继续当前策略）

  • • TACoS 逐周下降（哪怕只降 1-2%）
  • • 自然单占比逐周上升
  • • 核心词自然排名在爬升
  • • CVR 保持稳定或提升

⚠️ 警告信号（需要调整）

  • • TACoS 连续 3 周不降反升
  • • 自然单占比持续 <30%（3月+）
  • • CVR 突然下降（可能有新竞品/差评）
  • • 某个词 CPC 突然暴涨（竞品抢词）

🚨 危险信号（暂停审视）

  • • TACoS >30% 持续 2 月+ 且无下降趋势
  • • 广告花费 > 毛利 50% 持续 4 周+
  • • 推了 3 个月核心词依然在第 3 页以后
  • → 可能产品本身不适合这个市场/价位
趋势 > 绝对值：TACoS 从 30% 降到 25% 比从 15% 降到 14% 更有意义。 关注变化方向，不要纠结于某一周的具体数字。
