静态Toast样式测试

这些是直接使用CSS类的静态Toast，用于验证CSS是否正确加载：

Success - 应该是绿色渐变
Error - 应该是红色渐变
Warning - 应该是橙色渐变
Info - 应该是蓝色渐变

CSS变量检查

CSS变量测试 - 应该是绿色
圆角测试 - 应该有圆角

计算样式检查指南

  1. 打开浏览器开发者工具（F12）
  2. 选择上面的任意一个Toast元素
  3. 查看"计算样式"或"Computed"标签
  4. 检查 background 或 background-image 属性
  5. 应该看到 linear-gradient(...)
  6. 如果看到的是纯色或白色，说明样式被覆盖了
